# 题单详解

题单是按主题整理的题目合集，方便系统化地集中练习、专题复习或分享备考资料。

## 一、创建题单

在「题单」页面点击创建，填写：

- **标题**、**简介**：说明题单主题与学习路径。
- **科目 / 标签**：标记涉及学科与知识点标签，便于他人检索。
- **可见性**：
  - **公开**：对全站可见。**公开题单需要管理员审核**后发布。
  - **私有**：仅自己可见，或关联到指定团队后团队内可见。

::: note 公开前先想好
公开题单需要管理员审核后才会对全站可见；若只想小范围分享，也可先把题单设为私有并关联到你的团队。
:::

## 二、管理题单题目

- **添加题目**：从题库按题号或搜索添加题目进入题单。
- **移除题目**：从题单中删除某题。
- **排序**：拖拽调整题目顺序，形成循序渐进的学习路径。
- **备注**：可为题单内某题添加备注说明。

## 三、浏览与使用

- 公开题单在「题单」列表可见，可按关键词、科目、类型、标签检索。
- 进入题单可顺序 / 按需练习其中的所有题目，客观题正常自动判题，主观题正常批改。
- 「我的题单」集中管理自己创建的（含被拒 / 待审）题单，可编辑、删除。

## 四、审核

- 公开题单提交后进入**待审**，管理员批准后对全站可见；被拒会附拒绝原因。
- 题单的增改同样联动工单系统记录。

## 五、大题结构与导出

从 v1.0 起，题单可像组卷一样配置**大题结构**并直接导出试卷：

1. 打开题单的**编辑 / 管理**页，把题目**分入「大题」**（如「一、选择题」「二、解答题」），为每个大题设置**标题**与**每题分值**；不配置时按原有平铺顺序展示。
2. 点「**导出试卷**」把题单（连同大题结构）导出为 **PDF**。
3. 也可在**组卷**时选择该题单，**一键继承**其题目与大题结构（见[组卷详解](/basic/paper)）。

## 六、应用场景

- 老师整理「单元专题」练习卷。
- 同学分享「考前冲刺」资料集。
- 作为比赛 / 作业 / 组卷的**题目来源**：比赛添加题目、团队布置作业、组卷时均可选择从题单**继承题目**（见[比赛详解](/basic/competition)、[团队详解](/basic/team)、[组卷详解](/basic/paper)）。
