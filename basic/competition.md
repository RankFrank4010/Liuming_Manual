# 比赛详解

比赛是流明的在线竞赛功能：你可以**组织一场竞赛**（自定义题目、命题人、批改人与参赛者），也可以**报名参赛**，实时排名检验实力。

## 一、创建比赛

在「比赛」页点击创建，填写：

- **标题、描述**：说明比赛主题与规则。
- **可见性**：
  - **公开**：向全站开放，可自由报名；公开比赛需**管理员审核**后发布。
  - **私有**：仅通过邀请或邀请码的指定参赛者可见。
  - **团队私有**：仅绑定团队内可见。
- **批改方式**：
  - **仅创建者批改**：所有主观题只由创建者判分。
  - **指定批改人**：由指定的多名批改人共同判分。
  - **参赛者自批**：参赛者自己批改自己的主观题。
- **科目 / 题目**：指定涉及科目，并添加题目（可从题库选，也可自定义题干、答案、题解）。
- **时间**：设定开始、结束时间（也可手动随时开始 / 结束）。

### 管理题目

- **添加题目**：从题库选题，或现场自定义一道题（题干、题型、答案、题解、科目、学段、标签）。
- **编辑 / 移除**：可更新某道题内容、删除题目。
- **顺序**：可按顺序排列调整题目在比赛中的先后。
- **发布题目**：题目配置完成后「发布题目」使参赛者可见（客观题在作答时才显示）。

## 二、命题协作（命题人）

创建者可**邀请命题人**共同维护比赛题目。命题人可添加、编辑题目与配置。命题人由创建者添加 / 移除。

## 三、参赛与加入

- **公开比赛**：一键「加入」成为参赛者。
- **私有 / 团队私有比赛**：通过**邀请码**加入，或被邀请者在邀请中「接受」加入。
- 参赛者可随时**退出**比赛；管理员 / 创建者可移除某参赛者。

## 四、在线作答与判题

- **作答**：参赛者在比赛中逐题作答提交（客观题即时判定）。
- **判分**：
  - 客观题（填空、选择、阅读理解、小猫钓鱼）由系统自动判分。
  - 主观题（简答、作文等无标准答案题型）根据批改方式，由**批改人**或**参赛者自批**判定正确与否。
  - **口语题**：支持录音作答，AI 自动评分（0~10 分，0.5 步进），读取学生录音按参考文本打分。
- 每次提交记录判分结果与分析，批改人视图集中展示每道题所有参赛者的提交与待批状态。
- **排行榜口语总分**：竞赛排行榜包含口语题总分，反映参赛者的口语水平。

## 五、排行榜

实时**排行榜**按作答情况展示参赛者：

- 答对数 / 正确数、已提交数 / 待批数、总分。
- 排行榜含题目总数与比赛当前状态，直观反映领先与待批情况。

## 六、导出试卷

比赛可**一键导出试卷**：

1. 在比赛的**管理页**把题目**分入「大题」**（如「一、选择题」「二、解答题」）并设置标题与分值（对齐组卷的大题结构，v1.0 起支持）。
2. 点「**导出试卷**」，按题目顺序生成 **PDF**（后端 LaTeX 编译）。
3. 附带题解（教师版）仅管理员可用，适合赛前打印、赛后讲解。

## 七、重现赛

创建者可对已结束比赛开启**重现赛**：克隆原比赛的全部题目与配置，重置为一个全新比赛实例（新的起止时间），实现：

- 同题反复练习或模拟；
- 举办系列赛 / 复赛与决赛同题。

重现赛的可见性可自定义：设为公开需管理员审核。

## 八、管理与审核

- **比赛列表**：按状态（草稿 / 进行中 / 已结束）与科目筛选，查看参与人数与题量。
- **创建者管理**：编辑描述 / 批改方式 / 可见性 / 科目，删除比赛，开始 / 结束赛事。
- **管理员审核**：公开、团队公有等需要审核的比赛，管理员在后台批准 / 拒绝（附原因）。
- **计分（分数）**：比赛题可配置分值与评分规则，纳入总分与排名。
