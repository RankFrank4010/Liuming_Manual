# 账户与安全详解

本页介绍流明的账户体系、封禁与申诉流程、举报与工单系统，以及防止不合理浪费服务器资源的行为，帮助理解平台的治理与安全设计。

## 一、账户与登录

- **统一身份（手机号）**：支持**用户名 + 密码、手机号 + 短信、Passkey（指纹 / 面容免密）、OTP 动态验证码**等多种登录方式，可自由组合（详见[注册与登录](/basic/account)）。支持安全登录与自动续期。你只需要一个已认证的手机号即可访问流明，无需额外注册。
- **资料自动同步**：每次登录时自动同步个人资料（用户名、邮箱、姓名、头像、角色等），无需手动维护。
- **角色**：用户分为**普通用户**与**管理员**；管理员可进入后台完成治理与配置。
- **公开档案**：他人可通过你的个人主页查看你的练习热力图、答题记录与近期题目；公开信息仅包含允许展示的内容，并会明确显示封禁状态。
- **学习与编辑器设置**：在「账户设置」中可维护你的**身份 / 学段**（用于学习画像），并在「编辑器模式」中选择**可视化模式**还是**代码模式**（见[输入与编辑器详解](/basic/editor)）。

::: tip 关于隐私
普通接口不会返回你的隐私数据；**公开档案**只对外暴露允许展示的字段，且封禁状态对外可见。
:::

## 二、封禁与违规周期

### 封禁工单

每一次封禁都以**工单**形式完整记录，可以看到“是谁发起的 → 如何处置 → 是否申诉 → 最终结果”，全程可追溯。主要状态包括：

- **待裁决**：管理员尚未做出决定。
- **封禁中**：已生效，包含时长（临时到期自动解除 / 永久）与具体限制项（如限制练习、组卷、比赛等）。
- **申诉中 / 复核中**：你已提交申诉，等待复核。
- **已结束 / 已撤销 / 不予处罚 / 已关闭**：各种终态。

### 违规周期

每一次被封禁构成一个**违规周期**，集中记录该周期内的违规情况：

- 记录起止时间、是否**累犯**（反复违规会加重处理）、可人工延长期限等。
- 周期内含多条违规记录（限制项、说明、罚时）。
- 公开可查询当前与历史的违规周期。

### 封禁反馈

::: danger 被封禁后会怎样？
当你的账号处于封禁状态时，访问需要登录的功能会收到**明确的封禁提示**（含原因与封禁状态），并引导你进入申诉流程。
:::

## 三、申诉

### 封禁申诉

被封禁用户可对封禁工单提交**申诉**并附理由：

- 管理员可作出：**批准（解封）**、**驳回（维持）**、**调整处罚（改判）**或**要求补充材料**。
- 若被要求补充，你可**补充说明**后重新复核；也可由管理员**撤销**封禁。

::: tip 想提高申诉成功率？
在申诉理由中尽量写清事实经过与你的立场。若被要求补充材料，请按时补齐，否则申诉可能不会被继续处理。
:::

### 内容申诉

对**被拒绝**的题目 / 题单贡献，可提起申诉请求复核，管理员处理后给出最终结果。

## 四、举报与工单系统

举报与内容审核统一在**工单系统**中流转，覆盖题目 / 题单：

- 每次状态变更都会生成一条**事件**（操作人、原因、时间），形成**可追溯的处理时间线**。
- 工单附带目标的标题、创建人与最新事件，便于后台检索与核对。

### 用户侧

- **我的工单**：查看自己所有题目 / 题单的审核状态与事件。
- **我的贡献**：汇总自己的题目与题单审核结果（含被拒原因）。
- **发起举报**：对违规的题目 / 题单提交举报（附理由），会同步创建工单与事件。
- **申诉**：仅对被**拒绝**的工单可发起申诉。

### 管理侧

- 按状态、目标类型检索全部工单；查看待审 / 通过 / 拒绝 / 申诉中的数量。
- 处理申诉（批准 / 驳回）、处理举报（属实已处理 / 不予处理，可附说明）。

## 五、防止不合理浪费服务器资源

平台设有必要的机制，防止不合理浪费服务器资源的行为（如批量抓取、脚本化访问等）：

- 对异常的大批量请求、脚本化访问等行为，平台会**自动采取临时限制措施**，必要时由管理员对相关账号或来源施加访问限制。
- 请求设有合理超时，避免长时间等待；封禁状态会明确反馈并触发全局提示。

::: tip
以上措施对正常用户**透明无感**：正常使用网页与功能无需做任何操作。只要不使用脚本 / 批量爬取，不会受到任何影响。
:::

::: danger 请勿试探
具体判定方式属于平台内部信息，不会公开。**刻意试探、绕过或攻击上述机制本身即属违规**，将按[社区规则及处罚](/policies/rule)处理。
:::

## 六、管理后台

管理员可使用以下后台能力：

- **用户管理**：检索用户、查看套餐与额度、调整角色。
- **封禁管理**：创建、裁决、申诉复核、撤销封禁。
- **资源使用管理**：维护防止不合理浪费服务器资源的相关限制（具体策略不对外公开）。
- **内容治理**：处理题目 / 题单审核、举报、申诉。
- **学科管理**：配置学科代码前缀、学段与评分参数（见[题库详解](/basic/bank)）。
- **套餐管理**：维护套餐额度、为用户分配套餐与额外额度（见[批改中心](/basic/grading#五、额度管理)）。
- **AI 批改配置**：配置模型、参数与限额，含**视觉模型**（图题批改）与**系统 TTS**（听力朗读）配置（见[批改中心](/basic/grading)）。
- **审核设置**：进入「审核设置」页，切换「**贡献题目需要审核**」「**管理员更改题目需要审核**」两个开关（需要审核 / 免审核），点「**保存**」立即生效。默认均为需要审核。
- **团队 / 集团管理**：进入「团队」管理页，审核团队 / 集团申请、查看与管理子团队（见[团队详解](/basic/team)）。

::: note
管理员后台不属于普通用户的使用范围，这里仅供了解；相关入口与更多细节见对应功能文档。
:::
