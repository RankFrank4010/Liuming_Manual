# 组卷详解

组卷让你**输入题号即可自动生成一份排版专业的试卷 PDF**，适用于单元测试、期中期末、专题练习、口算卷等场景。

进入「组卷」页面，输入题号、解析题目列表后即可配置并导出试卷。

## 一、选择题目（按题号）

1. **输入题号**：在「题号列表」中每行一个题号（如 `M0001` / `C0002`），也支持逗号或空格分隔。一次最多查询 100 个题号。
2. **解析题号**：点击「确定题号」，系统按题号批量查询**已发布**题目：
   - 命中的题目进入「题目列表」；
   - 未命中的题号会明确提示「未找到」，可核对后重新输入。
3. **管理列表**：可逐个「移除」误选题目，「清空」全部；题目保留各自选项、题型等公开信息，供排版渲染。


::: warning 关于答案与题解
组卷查询的题目默认**不含标准答案与题解**（教育部不允许把答案直接暴露）；仅教师 / 管理员可请求附带题解（教师版 PDF）。
:::

### AI 智能组题

除手动输入题号外，还可用自然语言让 AI 自动组卷：

1. 在「组卷」页点击「**AI 组题**」，打开「AI 智能组题」对话框。
2. 在「**组卷需求**」中写下卷子要求（学段 / 学科 / 考查范围 / 题型与题量 / 难度 / 满分 / 时长），可另外「**限定学科**」与设置「**选题数量上限**（1~50）」。
3. 点「**AI 智能组题**」，约十几秒后查看生成的「**试卷结构**」（按大题列出题号与分值）；可「重新组题」，或点「**应用到组卷**」把题目与分值回填到题号列表。

每次组题消耗 1 次 AI 额度（失败自动退回），已在列表中的题目会自动去重。**完整操作步骤与写法建议见 [AI 智能组题使用指南](/basic/ai-compose)。**


## 二、配置试卷

- **试卷标题 / 副标题 / 学科**：标题默认「流明组卷」可自定义；可设置**副标题**（显示在主标题正下方，可空）与**学科**（可选「自动（按题目推断）」或手动指定，影响分科排版）。
- **总分 / 完卷时间**：设置全卷总分与建议时长。
- **显示分值**：可为每道题配置分值，支持**自动均分**；系统会校验「已配分数之和」与总分是否一致。
- **考生须知**：标题下方、题目上方的说明文字（如「1. 考试时间为 120 分钟…」）。
- **页脚**：可显示「第 N 页（共 M 页）」。
- **大题分组**：将小题拖入「大题」，为每个大题设置标题（如「一、现代文阅读」）与分值；大题按内小题自动汇总「共 X 小题，共 Y 分」。
- **作文作答区**：作文题可设置作答区样式——自动（按学科）/ 方格作文纸 / 横线 / 无作答区，并可调行数、每行方格数、行距。
- **防复制**：可开启防复制，保护卷面。
- **图片大小**：控制题面插图的缩放，并自动生成「第 N 题图」标注。

### 计算题组

可在一份卷子里插入**计算题组**：选择分类、难度、题数与分值，系统会生成一批**确定性**计算题并渲染进 PDF（样例构成与在线刷练的同一批题规则一致），适合制作口算 / 计算卷。

### 听力试卷生成

支持英语听力试卷生成，听力音频独立成页：

- **听力音频生成**：支持 TTS 语音合成生成听力音频，可配置声别（男声/女声）与朗读遍数。
- **声别配置**：支持全男/全女/先男后女/先女后男等多种声别组合模式。
- **多遍朗读**：听力音频可设置朗读遍数，朗读两遍及以上的大题可逐遍配读速。
- **独立成页**：听力音频在 PDF 中独立成页，便于打印与播放。

## 三、两种排版

### 简易排版

快速生成、上手简单，提供几种作答布局：

- **填空作答**：题目按空位排版。
- **选择作答**：选择题以选项形式排版。
- **答题卡模式**：选择题 / 填空题以填涂卡形式排版，供集中作答与机器阅卷。

简易排版同样可配置字号等基础项（按比例缩放）。

### 复杂排版

基于 **LaTeX exam-zh** 模板，提供最大程度的精细控制，分项包括：

- **页面 / 纸张**：A4 / A3 / 自定义（自定义可设页边距、页面尺寸）、页眉文字、页脚类型。
- **字体**：西文字体（newcm / lm / times / stix / libertinus / garamond 等）、数学字体（cambria / stix / xits 等）、正文字号（pt）。
- **密封线**：出现范围（每页 / 仅首页 / 仅奇数页 / 首尾页）、线型（实线 / 虚线 / 点线等）、是否显示圆圈、密封线内考生信息（姓名 / 考号 / 班级 / 座位号，可自定义标签与宽度）。
- **考生信息栏**：姓名 / 考号 / 班级 / 座位号，考号可配置填涂位数（8 / 9 / 10 位）。
- **选择题排版**：选项列数（自动 / 1–4 列）、选项标签（带圈数字等）、选项间距。
- **填空样式**：下划线 / 括号 / 圆圈 / 矩形 / 空白，可设宽度。
- **题目间距**：题目前 / 后的弹性间距。
- **答题卡涂卡配置**：填涂图例、考号涂卡表位数。
- **题册模式**：生成题册封面（第一页为说明封面），封面内容可用 Markdown 说明；可为非选择题 / 填空题预留空白作答区。
- **教师版 / 题解**：可配置在填空 / 括号 / 选择内**显示答案**、**随附题解**（显示方式：隐藏 / 停留 / 上翻转移）、评分框样式等。
- **草稿纸 / 评分框 / 信息方格 / 列表名称**等进阶项。

## 四、预览与导出

- **预览试卷**：导出前可先预览整份试卷（前端按同样排版渲染，含计算题组预览）。
- **导出 PDF**：后端用 LaTeX 编译生成 PDF（纯二进制流，页面公式排版专业），下载到本地。
- 附带题解的教师版 PDF：仅管理员 / 有相应权限者可用。
- **在线保存 / 下载 / 导入**：组卷「稿件」可在线保存（标题 + 完整配置），随时读取继续编辑；可导出草稿、再导入。

::: warning 关于外部图片
题目题干中的外部网络图片若因跨域限制无法嵌入，导出时会提示并从导出中移除（例如「有 N 张外部图片因跨域限制无法嵌入」）。
:::

## 从题单 / 比赛带入

可通过选择题单或比赛，将其中题目**有序导入**当前组卷，便于快速基于已有材料组卷。

## 额度说明

组卷（PDF 导出）按**套餐**享有**每周使用额度**，额外额度由管理员授予；剩余额度在「个人中心」实时可见（详见[批改与组卷额度](/basic/grading#五、额度管理)）。
