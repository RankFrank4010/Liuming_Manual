# 听力音频片段剪辑使用指南

组卷听力时，可为听力**大题**插入**音频片段**——从题目音频中截取需要的区间。系统 TTS 生成的「**流明听力**」可**整段直通**；**上传的 MP3** 音频可**先剪辑再插入**。

本页讲**怎么操作**；听力试卷与 TTS 配置见[听力 TTS 详解](/basic/listening)。

## 一、在哪里用

1. 进入「组卷」页面，打开**听力编辑器**。
2. 在某个**听力大题**下，点击「**音频片段**」（添加音频片段）。

## 二、选择题目音频

1. 点击后弹出「**选择题目音频**」。
2. 用**题号或题面关键词**搜索，选择要插入的题目音频。
3. 每条音频标有来源徽标：
   - **流明听力**：系统 TTS 生成，**整段直通**（无需剪辑）；
   - **上传音频**：上传的 MP3，可**先剪辑再插入**。
4. 点击「**整段插入**」直接插入；或点击「**剪辑后插入**」进入剪辑编辑器。

## 三、剪辑音频（听力剪辑编辑器）

1. 打开「**听力剪辑编辑器**」，等待**波形解析**完成（失败会提示「音频加载失败」）。
2. 在波形上**拖拽框选**要保留的区间；拖动**两侧手柄微调**起止点。
   - 顶部显示「时长 Ns」与「已选 s–e s」；未框选时提示「未框选（使用整段）」。
   - 可用「**全选**」「**清除选区**」快速操作。
3. 点「**保存选区**」保存区间，或点「**剪辑后插入**」把所选区间插入到听力。
4. 已插入的片段显示区间「{s}s–{e}s」或「整段」，可点「**调整剪辑**」重新编辑。

## 四、常见问题

- **音频加载失败 / 解析失败**：多为音频格式或体积问题，换一个音频或重新上传再试。
- **没框选就插入**：等同「整段」，即使用完整音频。
- **上传音频整段直通？** 不会——只有「流明听力」（系统 TTS 生成）整段直通；上传的 MP3 需要自行剪辑。
