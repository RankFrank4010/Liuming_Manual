# 整卷库详解

整卷库是流明的整卷资源共享社区：任何用户都可以**上传一份完整试卷文件**（PDF / Word / PPT / TXT）分享给社区，也可以**浏览、下载**别人上传的整卷试卷。适合分享期中 / 期末 / 模拟卷、单元卷等成套试卷。

> 整卷库（整份试卷文件）与「[组卷](/basic/paper)」生成功能不同：组卷是**在线按题号生成**试卷 PDF；整卷库则是**上传真实的完整试卷文件**供社区共享。

## 一、浏览与下载

登录后进入「整卷库」页面即可浏览社区上传的整卷：

- **全部 / 我的上传**：可切换查看社区全部整卷，还是只看自己上传的。
- **按状态筛选**：待审核 / 已通过 / 已拒绝。
- 每份整卷展示：**科目、学段、标题、上传者、文件类型 / 大小、上传时间、状态、下载次数**。
- 点击「**下载**」即可把对应试卷文件下载到本地（需登录）。

## 二、上传整卷

任何人（需登录）都可上传，流程如下：

1. 点击「**上传整卷**」。
2. 填写：
   - **试卷标题**（必填）。
   - **科目**、**学段**（用于分类与检索）。
   - **描述**（选填）：试卷说明、来源、适用年级等。
   - **文件**（必填）：支持 **PDF / Word / PPT / TXT**，单个文件最大 **50MB**。
3. 可选「**关联题单**」：将一个或多个公开题单与这份卷关联，便于浏览者发现其配套的题目练习。
4. 提交后状态为**待审核**，等待管理员审核。

## 三、审核与状态

上传的整卷需管理员审核后才对社区可见：

| 状态 | 含义 |
| --- | --- |
| **待审核** | 已提交，等待管理员处理（仅你自己在「我的上传」可见）。 |
| **已通过** | 审核通过，对社区可见，可被下载，出现在「全部」列表。 |
| **已拒绝** | 未通过，会附**拒绝原因**；若有需要你可以重新上传修改。 |

管理员在「整卷审核」中处理：**通过** / **拒绝**（可选填原因）/ **删除**。

## 四、举报违规整卷

若发现某份整卷存在「内容违规、侵权、垃圾信息」等问题，可对该整卷发起**举报**并填写举报原因。举报会进入[工单系统](/basic/account-safety#四、举报与工单系统)由管理员复核处理。

## 相关
