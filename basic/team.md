# 团队详解

团队是面向班级、社团、兴趣小组的协作空间：管理成员、共享私题、布置作业、举办团队比赛，并统一统计成员表现。

## 一、创建与加入团队

- **创建团队**：填写名称、描述与**申请理由**即可创建，创建者自动成为团队**管理员**；团队创建后需**审核**（详见下文「团队审核」）。
- **邀请成员**：管理员通过用户搜索邀请成员；成员收到邀请后可**接受 / 拒绝**。
- **加入团队**：可凭**团队邀请码**查看团队并申请 / 加入。
- **角色**：成员分为**管理员**与**普通成员**两种。
- **成员管理**：管理员可提升 / 降级成员角色、移除成员；成员可退出 / 拒绝团队。
- 团队信息可编辑（名称、描述），团队可由创建者删除。
- 团队列表展示每位成员的状态（已邀请 / 已加入 / 已拒绝）与成员数。

## 二、团队审核

为防止滥用，**新建团队需要管理员审核**后才能正常使用：

- 创建团队时需填写**申请理由**（创建理由 / 用途说明）。
- 创建后团队状态为**待审核（pending）**；在审核通过前，创建者尚未成为正式成员。
- 管理员在后台审核：**通过**（自动将创建者加入为团队管理员）或 **拒绝**（可附审核备注 / 拒绝原因）。
- 审核状态（待审核 / 已通过 / 已拒绝）在团队列表中可见；被拒绝时可重新创建或联系管理员。

## 三、团队私题

团队题库是**仅本团队可见**的私有题目，供团队内部使用：

- **创建私题**：填写标题、题干（Markdown）、题型、学科、学段、答案、题解。
- **编辑 / 删除**：按权限管理团队私题。
- **应用场景**：团队私题可用于布置**作业**，也可带入**组卷**。

## 四、作业系统

作业让团队能统一布置、批改、统计练习任务。

### 布置作业

- 从三种来源挑题：**题库**（全局题目）、**团队私题**、或**继承自题单 / 比赛**的题序列表。
- 设定**标题、说明**、可选**截止时间**与指定**参与成员**。

### 学生作答

- 成员在作业中逐题作答并提交；客观题自动判分，主观题由带权批改（正确 / 错误 / 待批）。
- **口语题**：支持录音作答，AI 自动评分（0~10 分，0.5 步进），读取学生录音按参考文本打分。
- 每次提交有独立记录（提交答案、正确与否、判分结果）。

### 作业管理（管理员）

- **改题**：单独修改某题的题干 / 答案 / 题解（仅覆盖本次作业，**不影响题库**）。
- **增删 / 排序**：向末尾加题、删除某题、全量替换作业题目（一次提交完成增 / 删 / 改 / 排序）。
- **组卷**：可将作业题目导出 / 用于组卷。

### 统计与排行榜

- **作业统计**：总题数、参与人数、已提交 / 答对人数、总提交数。
- **排行榜**：按提交率 / 答对数 / 完成率排名。
- **导出 CSV**：一键导出作业成绩单（姓名、提交、答对、完成率等）为 CSV 文件下载。

## 五、团队比赛

- 团队内可创建**团队私有比赛**（持有专属邀请码），作为内部赛开展。
- 参赛通过邀请码加入；客观题自动判题、主观题按配置批改。
- 团队比赛拥有独立排名与数据统计。

## 六、团队数据看板

团队主页集中展示：

- **成员结构**：已加入 / 已邀请 / 已拒绝 / 管理员数。
- **资源数量**：团队私题数、比赛数（草稿 / 进行中 / 已结束）、作业数。
- **作业提交**：总提交数、正确 / 错误 / 待批。
- **比赛提交**：总 / 正确 / 错误。
- **成员贡献排行榜**：每位成员出题数、作业提交与正确率、比赛提交与正确率，一目了然。

其中比赛、作业的相关数据与个人[学习数据](/basic/practice-stats)体系相互独立、按团队维度聚合。

::: tip 作业与题库互不影响
你在作业里「改题」（单独修改某题的内容）只影响本次作业，**不会改动题库里的原题**，可放心使用。
:::

## 七、集团模式（v1.0+）

**集团**（kind=`group`）是团队的更高形态：一个集团下可以挂多个**子团队**，集团管理员在每个子团队中都拥有与子团队管理员同等的权限。适用于**多班级 / 多项目**的统一管理。

### 7.1 集团与子团队

1. **创建集团**：与创建团队相同的入口，把表单切换到「**集团**」提交（同样需平台审核）；审核通过后你成为集团管理员。
2. **创建子团队**：进入集团主页的「**子团队**」标签页，点创建（**无需平台审核**），填写名称、描述与默认计分规则。
3. **成员默认跟随**：创建子团队时，当前已加入集团的成员会自动加入为普通成员；子团队管理员需单独配置。
4. **管理子团队**：在「子团队」列表查看成员数与状态，点击进入任一子团队即可执行子团队管理员操作（编辑题目、批改、删除）。

**权限与限制**：

- 集团管理员对集团本身有完整控制权，对**每个子团队**都**等同于子团队管理员**；**不能**干预兄弟集团（权限以 `parent_id` 为界）。
- **不支持嵌套**（v1）：集团不能作为另一个集团的子节点，也不能有 `parent_id`。

### 7.2 集团排行

集团主页新增**「集团排行」**标签页，按以下维度对比各子团队：

- 成员数、作业提交总数、答对总数、**优秀数**、比赛数、参与人数。
- 默认排序：成员数降序、名称升序。
- 用于一眼看出各子团队的活跃度与产出。

### 7.3 子团队管理

在**「子团队」**标签页，集团管理员可以：

- 创建子团队（名称、描述、默认计分规则）。
- 浏览所有子团队（成员数、审核状态、创建时间）。
- 点击进入任一子团队，执行任意子团队管理员操作（编辑题目、批改、删除）。

## 八、团队事件计分

从 v1.0 起，团队支持**事件计分**体系用于内部排名。管理员可调整规则；成员按总积分排名；账本可审计，并支持手动调整。

### 默认规则（创建团队时初始化）

| 事件 | 默认分值 | 触发条件 |
| --- | --- | --- |
| 作业提交 | +2 | 每位学员每道题的首次提交 |
| 作业答对 | +3 | 每位学员每道题的首次正确判定（AC，人工或自动） |
| 口语评分 | +1 | 每次口语提交被评分一次 |
| 优秀作业 | +10 | 管理员将某次提交标记为优秀时 |
| 创建题目 | +5 | 团队题成功创建时 |
| 参加比赛 | +5 | 学员在某场团队比赛中的首次提交 |
| 比赛答对 | +5 | 学员在某场团队比赛中的首次 AC |
| 手动调整 | -100 ~ +100 | 管理员录入；**必须填写备注**以便审计 |

> **防刷分**：每位学员每个 `(题目, 事件)` 只计一次；一次提交的「优秀作业」只计一次（取消标记会冲销）；一场比赛每位学员每个事件只计一次。

### 计分管理

- **规则**（仅管理员）：在**「排行 → 规则」**子标签页调整每个事件的分值（-100 ~ +100）或停用某事件。已记录的事件保持原值——账本就是历史记录。
- **排行榜**（所有人）：按 `total_points DESC, joined_at ASC` 排序；已加入但 0 分的成员也会显示。
- **账本**（成员看自己，管理员可看任何人）：每条事件含时间、成员、事件、分值、备注、操作者；可按用户筛选。
- **手动调整**（仅管理员）：规则标签页底部的表单——选择目标成员、分值（可为负）与必填备注。

### 入口位置

- 团队主页 → **「排行」**标签页：排行榜、规则、账本、手动调整表单。
- 集团主页 → **「集团排行」**标签页：子团队对比。
- 成员贡献排行榜：新增两列——**优秀数（excellent_count）** 与 **总积分（total_points）**。

## 九、优秀作业

从 v1.0 起，团队管理员可将任意提交标记为**优秀作业**。团队主页新增**「优秀」**标签页，全员可浏览；标记时会自动加分。

### 标记 / 取消标记（管理员）

- 在作业的**「批改」**标签页，每条提交都有「标记优秀 / 取消标记」开关。
- 标记后，该提交对团队全体成员在「优秀」标签页可见。
- 取消标记会**冲销** `excellent_homework` 账本记录，避免重复奖励。

### 展示区

- 团队主页 → **「优秀」**标签页：按 `excellent_at DESC`，默认展示最近 **30 条**（可配置）。
- 每张卡片展示：作业标题、题目、学生、答案、判定（AC / WA / SCORED）、分数（口语题）、`excellent_at`、标记人。
- 学生可在个人「我的作业」视图看到自己被标记的提交。

### 积分影响

- 标记 → `excellent_homework` +10（默认），自动写入账本。
- 取消标记 → 账本记录冲销。
- 计入成员排行榜总分与 **优秀数（excellent_count）** 列。

## 十、优秀答案（团队 / 作业）

从 v1.0 起，团队题与作业题支持设置**优秀答案**字段，供管理员作为学员参考。详见[题目与题单规范：优秀答案](/academic/problem#优秀答案)。
