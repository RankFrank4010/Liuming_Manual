# 团队详解

团队是面向班级、社团、兴趣小组的协作空间：管理成员、共享私题、布置作业、举办团队比赛，并统一统计成员表现。

## 一、创建与加入团队

- **创建团队**：填写名称、描述与**申请理由**即可创建，创建者自动成为团队**管理员**；团队创建后需**审核**（详见下文「团队审核」）。
- **邀请成员**：管理员通过用户搜索邀请成员；成员收到邀请后可**接受 / 拒绝**。
- **加入团队**：可凭**团队邀请码**查看团队并申请 / 加入。
- **角色**：成员分为**管理员**与**普通成员**两种。
- **成员管理**：管理员可提升 / 降级成员角色、移除成员；成员可退出 / 拒绝团队。
- 团队信息可编辑（名称、描述），团队可由创建者删除。
- 团队列表展示每位成员的状态（已邀请 / 已加入 / 已拒绝）与成员数。

## 一、团队审核

为防止滥用，**新建团队需要管理员审核**后才能正常使用：

- 创建团队时需填写**申请理由**（创建理由 / 用途说明）。
- 创建后团队状态为**待审核（pending）**；在审核通过前，创建者尚未成为正式成员。
- 管理员在后台审核：**通过**（自动将创建者加入为团队管理员）或 **拒绝**（可附审核备注 / 拒绝原因）。
- 审核状态（待审核 / 已通过 / 已拒绝）在团队列表中可见；被拒绝时可重新创建或联系管理员。

## 一、团队私题

团队题库是**仅本团队可见**的私有题目，供团队内部使用：

- **创建私题**：填写标题、题干（Markdown）、题型、学科、学段、答案、题解。
- **编辑 / 删除**：按权限管理团队私题。
- **应用场景**：团队私题可用于布置**作业**，也可带入**组卷**。

## 二、作业系统

作业让团队能统一布置、批改、统计练习任务。

### 布置作业

- 从三种来源挑题：**题库**（全局题目）、**团队私题**、或**继承自题单 / 比赛**的题序列表。
- 设定**标题、说明**、可选**截止时间**与指定**参与成员**。

### 学生作答

- 成员在作业中逐题作答并提交；客观题自动判分，主观题由带权批改（正确 / 错误 / 待批）。
- 每次提交有独立记录（提交答案、正确与否、判分结果）。

### 作业管理（管理员）

- **改题**：单独修改某题的题干 / 答案 / 题解（仅覆盖本次作业，**不影响题库**）。
- **增删 / 排序**：向末尾加题、删除某题、全量替换作业题目（一次提交完成增 / 删 / 改 / 排序）。
- **组卷**：可将作业题目导出 / 用于组卷。

### 统计与排行榜

- **作业统计**：总题数、参与人数、已提交 / 答对人数、总提交数。
- **排行榜**：按提交率 / 答对数 / 完成率排名。
- **导出 CSV**：一键导出作业成绩单（姓名、提交、答对、完成率等）为 CSV 文件下载。

## 二、团队比赛

- 团队内可创建**团队私有比赛**（持有专属邀请码），作为内部赛开展。
- 参赛通过邀请码加入；客观题自动判题、主观题按配置批改。
- 团队比赛拥有独立排名与数据统计。

## 二、团队数据看板

团队主页集中展示：

- **成员结构**：已加入 / 已邀请 / 已拒绝 / 管理员数。
- **资源数量**：团队私题数、比赛数（草稿 / 进行中 / 已结束）、作业数。
- **作业提交**：总提交数、正确 / 错误 / 待批。
- **比赛提交**：总 / 正确 / 错误。
- **成员贡献排行榜**：每位成员出题数、作业提交与正确率、比赛提交与正确率，一目了然。

其中比赛、作业的相关数据与个人[学习数据](/basic/practice-stats)体系相互独立、按团队维度聚合。

::: tip 作业与题库互不影响
你在作业里「改题」（单独修改某题的内容）只影响本次作业，**不会改动题库里的原题**，可放心使用。
:::
