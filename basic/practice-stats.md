# 学习数据与错题本详解

流明会自动记录你的每一次练习，生成多维度的学习画像，帮助你发现自己知识结构的强弱，从而更有针对性地复习。

## 一、练习统计

「个人中心 → 练习」展示你的整体练习概况：

- **总提交数**：累计作答的次数。
- **正确提交数 / 正确率**：正确次数与正确率百分比。
- **累计用时 / 平均用时**：总投入时间与每次平均用时。
- **连续打卡天数**：连续每日均有练习的天数，是坚持学习的直观反馈。
- **本周练习量**：本周完成的提交次数。

统计可按学科筛选，从而分别查看某一科的表现。

## 二、错题本

系统自动将你做错的题目收集进错题本：

- **查看**：列出所有错题，含题号、标题、学科、题型、难度星级、学段、标签、尝试次数、最近尝试时间。
- **筛选 / 检索**：支持按学科、关键词（标题 / 题号）检索，并分页浏览。
- **移除**：当某道错题已被你完全掌握、不打算再练时，可手动从错题本移除。

> 错题本与你的练习记录是联动的：未来若再次做错该题，会再次进入错题本。

## 三、知识点雷达

将练习数据按**学科 / 子学科**聚合，展示每个领域的练习量、答对量、平均用时与正确率，直观呈现知识结构强弱分布：

- 不指定学科时，按**主学科**聚合（数学、物理、化学等理科的子学科各自独立聚合）。
- 指定某主学科时，返回该学科下各**子学科**（如数学的代数、几何、微积分…）的细分数据。
- 正确率偏低的领域在雷达图上呈现「凹陷」，一眼定位知识短板。

## 四、知识图谱

把练习数据组织成**树状知识图谱**，每个知识点节点标记三级掌握状态：

- **已掌握**：正确率达标。
- **发展中**：正在进步。
- **薄弱**：正确率偏低，需要加强。

每个节点展示练习量、答对数、涉及的不同题目数与正确率。图谱支持按主学科隔离查看，便于聚焦单一学科。

## 五、薄弱点分析与题目推荐

系统基于全部练习数据：

1. 计算各个学科的正确率，找出**正确率明显偏低的「薄弱学科」**。
2. 给出**整体正确率**。
3. 针对薄弱学科与知识点，**推荐适合继续练习的题目**，帮助你精准补强。

首页未登录时展示通用欢迎页；登录后展示你的肖像、各项统计、薄弱点提醒与推荐题目。

::: tip 怎么利用薄弱点分析？
建议先看**知识点雷达**或**知识图谱**定位短板，再用「薄弱点分析」给出的推荐题目集中补强——这正是流明把学习数据自动聚集起来的价值所在。
:::

## 六、AI 学习分析

一键生成 **AI 学习分析报告**：系统根据你的练习数据（而非另行在此列出原始数据）调用 AI，输出针对性的文字分析，指出学习现状与改进建议。该功能用于辅助自我认知，最终效果以实际数据为准。

## 七、练习热力图

个人主页展示**过去一年的每日练习量**（GitHub 风格热力图）；点击某天可查看当日练习。逐日累计的格子直观呈现你的坚持与节奏。

## 八、公开档案与近期练习

- **公开档案**：通过你的公开主页，他人可查看你的昵称、头像、角色、加入时间、最近活跃时间、练习热力图、**提交记录列表**与**近期练习题目**。
- **练习记录**：按提交时间列出你练习过的题目（题号、标题、学科、题型、难度、学段、正确与否），支持筛选（学科 / 题型 / 对错）与分页。
- **搜索用户**：可按昵称搜索其他用户，访问其公开档案。

## 九、家长可查看

绑定监护关系后，**家长**可查看上述大部分学习数据（统计、提交、错题本、知识图谱、雷达、薄弱点、热力图、收藏、近期练习与 AI 分析）——详见[家长监护](/basic/guardian)。学生同意绑定后才可查看。
