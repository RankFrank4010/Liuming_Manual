# 输入与编辑器详解

流明的所有文字输入框（**题干、答案、题解、听力材料、比赛题目、团队私题、自定义题目**等）都使用同一套**通用编辑器**。本页教你如何用它输入普通文字与数学公式，尤其是**可视化编辑器**、**可视化输入公式**与**代码模式**三种用法。

## 一、编辑器模式

这套通用编辑器有两种模式，界面与写法不同，但**保存的数据格式都是 Markdown**，因此**随时切换、内容不丢失**：

| 模式 | 说明 | 适合人群 |
| --- | --- | --- |
| **可视化模式**（默认） | 所见即所得：用**可视化编辑器**直接排版文字，用菜单插入公式，公式即时渲染 | 不熟悉 Markdown / 想所见即所得的人 |
| **代码模式** | 传统 Markdown 源码编辑，带格式化工具栏与**可视化输入公式** | 熟悉 Markdown、想直接编辑源码的人 |

> 凡是用到的输入框，都会遵循你在「账户设置 → 编辑器模式」中做的选择。默认是**可视化模式**。

### 如何切换

1. 登录后进入「个人中心 → 账户设置」。
2. 找到「**编辑器模式**」一栏，在**可视化模式**与**代码模式**之间二选一。
3. 保存后，全站所有输入框（题目题干、答案、题解、听力材料……）都会按新模式显示。

> 切换只影响「编辑器长相与写法」，不会改变已输入内容的保存格式，也不会丢失任何内容。

此外，不是所有输入框都会启用公式功能：**数学、物理、化学、生物等理科**输入框会额外提供公式相关按钮；**语文、英语等文科**输入框只做普通文字编辑，不出现公式相关入口。

## 二、可视化编辑器（所见即所得）

可视化模式使用**可视化编辑器**：一个所见即所得的富文本工具栏 + 编辑区。你直接编辑排版，看到的效果就是最终效果；公式以**公式实体**形式插入，并即时渲染成数学符号。

### 常用操作

1. **排版文字**：使用工具栏按钮（标题、加粗、斜体、列表、引用、链接、代码、分割线……）即可，与 Word 等编辑器直觉一致。
2. **插入公式**：工具栏最前有一个**公式**按钮。点击后弹窗输入 LaTeX，确认后以公式形式插入，**在编辑区内即刻渲染**。
   - 行内公式会嵌入文字行中部；如需单独成行的公式，可把公式放行首或单独一行。
3. **编辑 / 删除公式**：**鼠标点选编辑器里的公式**，悬浮条会出现「编辑公式」，点它即可重新输入该公式的 LaTeX。
4. **保存后转换**：保存时编辑器会自动把内容转成 Markdown 并写回题目 / 答案。因此**无需任何额外操作**，你编辑的公式会自动变为可被判题识别的方式。

> 可视化编辑器不提供图片 / 视频上传（平台无相关后端），如需插图请改用其他方式（题干支持附件）。

## 三、可视化输入公式

可视化输入公式（在代码模式工具栏与可视化编辑器顶部都会出现，理科启用）是一种**图形化拼搭公式**的方式：你不需要记忆 LaTeX 语法，靠**点击符号、函数模板**即可把公式「搭」出来，并**实时预览**。

### 打开方式

- **可视化模式**下：在可视化编辑器的公式工具栏上方，会有一个「**可视化输入公式**」按钮，点击即可弹出公式拼装窗口。
- **代码模式**下：理科的 Markdown 编辑工具栏上有两个按钮——**行内公式（∑）** 与 **块级公式（∑²）**，点击即可打开公式拼装窗口。

### 界面与操作

弹出的是一个公式拼装窗口，大致分为：

1. **三个标签页**，点按切换：
   - **α 字母**：希腊字母（小写 α β γ δ … 及大写 Γ Δ Θ …），例如 π、σ、θ。
   - **± 符号**：运算与关系符号（+ − × ÷ ⋅ ≤ ≥ ≠ ≈ ∈ ∋ ⊂ ∪ ∩ ∞、积分 ∫ ∫ ∫、求和 ∑ 等），以及箭头、偏导 ∂、nabla ∇ 等。
   - **Σ 函数**：常用函数与结构模板，例如 **lim（极限）**、**平方根 sqrt**、**n 次方根**、**下标 / 上标 / 上下标**、**分数**，以及三角函数（sin cos tan 等）与反三角函数。
2. **拼装区 / 预览区**：随你的每一步点击**实时渲染**当前公式，直观看到拼装结果。
3. **左右方向按钮**：移动输入光标，往已在拼装的式子中定位。
4. **清空（🗑）**：清除当前拼装的公式。
5. **保存 / 确定（✓）**：把拼好的 LaTeX 送入输入框并关闭窗口。

### 拼装示例（以分数为例）

假设要输入分数 $\frac{1}{2}$：

1. 打开公式拼装窗口。
2. 切换到「函数」标签页，点击**分数 / frac** 模板。
3. 依次输入分子 `1` 与分母 `2`（用光标定位切换）。
4. 预览即显示 $\frac{1}{2}$；再点「确定」完成。

> 输入框**不需要会 LaTeX**。当你要用分式、根号、上下标、希腊字母、积分求和等结构时，可视化输入能让**点击值**生成公式；要输入普通文字时直接打字即可。

## 四、代码模式（Markdown）

若你切到「代码模式」，输入框会显示为 Markdown 源码编辑器，顶部有一排**格式化快捷按钮**并可插入公式。

### 常用快捷按钮

| 按钮 | 作用 | 说明 |
| --- | --- | --- |
| H1 / H2 / H3 | 各级标题 | 在当前行添加 `#` / `##` / `###` |
| B | 加粗 | `**加粗**`，快捷 Ctrl / ⌘ + B |
| I | 斜体 | `*斜体*`，快捷 Ctrl / ⌘ + I |
| <> | 行内代码 | `` `code` `` |
| ∑ 公式-行内 | 行内公式 | 用 **可视化输入公式** 拼公式并插入为 `$...$` |
| ∑² 公式-块级 | 块级公式 | 用 **可视化输入公式** 拼公式并插入为 `$$...$$` |
| ``` | 代码块 | 三反引号代码块 |
| 引用 | 引用块 | 行首加 `>` |
| 列表 | 无序 / 有序列表 | 行首加 `-` / `1.` |
| 🔗 | 链接 | `[文本](url)`（快捷 Ctrl / ⌘ + K） |
| 分割线 | 分割线 | 插入 `---` |
| Σ 符号 | 符号面板 | 点击打开数学符号面板，点选插入 |

### 数学符号面板

点「**Σ 符号**」会展开一个常用数学符号面板，包含：希腊字母（α β γ …）、无穷 ∞、求和 ∑、乘积 ∏、积分 ∫、偏导 ∂、nabla ∇、根号 √、不等式符号、`π`、`√`、上 / 下标、分式 `\frac{a}{b}`、组合 `\binom{n}{k}`、矩阵等等。点一下即插入到光标位置，右下角会显示**当前文字数**。

### 如何直接写公式

代码模式下你也可用可视化输入公式，或直接手写 LaTeX 包在 `$...$` 里（行内）或 `$$...$$`（块级）。公式语法遵循**KaTeX / LaTeX** 子集。

## 五、两种模式的对应关系

可视化模式与代码模式是**同一份 Markdown 内容的两张「脸」**：

- 在可视化模式里插入的公式 → 切换代码模式后，会以 `$...$` 形式出现在源码中。
- 你在代码模式里手写的 `$...$` → 切回可视化模式后，会被识别并渲染为公式。

所以无论用哪种模式输入公式，最后的存储都是一样的，判题、组卷、导出 PDF 都会把公式正确识别与排版。

## 六、题面可视化插入与绘图

在**贡献 / 编辑题目**时，题面编辑器上方有一排快捷按钮，点开即弹窗填写、实时预览，点「**插入**」写入题面：

- **插入古诗**：依次填写**题名 / 作者 / 诗句（每行一句）/ 注释**，点「插入」生成排版好的古诗题面（诗句至少一句）。
- **插入材料**：填写**标题 / 作者 / 出处 / 正文**（正文必填），点「插入」。模板里的 `# 标题`、`——作者`、`（选自《…》）` 三个惯例行会被导出自动识别。
- **插入连线**：填写**左列 / 右列**（各至少 2 项，每行一项）与可选的**第三列**，点「插入」；正确连线在**标准答案**中填写（如 `1-3, 2-1, 3-2`），项目内容不能含 `|`。
- **选项图**：在选择题的某个选项上点「图片」，为该选项插入图片（提交时随附件上传，显示在该选项上）。
- **TikZ / LaTeX 绘图**：在题面填写 TikZ / LaTeX 绘图代码，会插入到题面末尾；导出 PDF 时由 xelatex 编译渲染。
