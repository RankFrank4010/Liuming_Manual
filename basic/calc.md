# 计算专区详解

计算专区是为小学、初中计算能力训练设计的专项练习：**系统自动出题、自动批改**，无需人工判分，适合反复刷练口算与基础计算。

## 一、十类计算题型

覆盖以下十类题目，对应不同年级的运算训练：

| 分类 | 说明 |
| --- | --- |
| 口算 | 简单的口算加减乘除 |
| 四则巧算 | 运用运算律的巧妙计算 |
| 整式 | 整式运算 |
| 一元一次方程 | 一元一次方程求解 |
| 因式分解 | 因式分解练习 |
| 一次不等式 | 一次不等式求解 |
| 一次不等式组 | 一次不等式组求解 |
| 一元二次方程 | 一元二次方程求解 |
| 一次方程组 | 一次方程组求解 |
| 三角函数 | 特殊角三角函数求值 |

::: tip 小数、分数计算去哪了？
小数与分数不再作为独立题型，而是作为**计算选项**叠加在其他题型上（见下文「选项」）。选择对应选项后，题目的数字就可以包含小数或分数。
:::

## 二、选项

部分题型支持额外的数字选项，用来调节题目数字的取值范围：

- **允许负数**：数字可为负数。
- **允许小数**：数字可为小数（如 1.25）。
- **允许分数**：数字可为分数（如 3/4）。
- **允许无理数**：数字可为无理数（如 √2）。

三角函数题型支持以下函数选项：

- **含 sin**：题目中包含 sin 函数。
- **含 cos**：题目中包含 cos 函数。
- **含 tan**：题目中包含 tan 函数。

整式题型支持以下扩展选项：

- **含三角函数**：整式中包含三角函数（如 sinα、cosβ）。
- **含分式**：整式中包含分式（如 (x+1)/(x-2)）。

不同题型支持的选项不同，以页面显示为准。

## 三、难度

每个分类都支持三档难度：

- **简单**
- **中等**
- **困难**

难度用于控制题目的系数大小、运算步骤与复杂度。

## 四、生成一组题

1. 选择**分类**与**难度**。
2. 选择**题量**：10 / 20 / 30 道。
3. 系统生成一组题目并一次性展示。

**同一套题可复现**：每组题都带有一个固定「种子」，用它再生成一次会**得到完全相同的一组题**，因此可以：

- 重复刷练同一套题以强化记忆；
- 多人用同一套题做对比练习。

::: tip 怎么和别人做同一套题？
想要和同学对比，只需双方选择相同的分类、难度并生成同一批题（题量一致），就能得到完全相同的一组题进行同场对比。
:::

## 五、自动批改与结果反馈

作答完成后提交，系统对全组逐题批改：

- 逐题返回**是否正确**及其**标准答案**。
- 汇总：**总题数、答对数、正确率（整数百分比）**。

批改会记录用时与结果，纳入**我的计算练习统计**。

## 六、回答标准与判分规则

### 作答方式

- 每题在输入框中直接键入答案；也可以点击输入框旁的**「公式」**按钮打开 GUIMath 公式编辑器，用图形化方式输入分数、根号、上标等结构，确认后以 LaTeX 片段插入作答框。
- 提交后由系统自动判分，**逐题只有「对 / 错」两种结果，没有过程分或部分得分**。

### 输入归一化（所有题型通用）

判分前系统会对作答做统一清洗，以下书写差异**不影响判定**：

- 全角字符自动转半角（如 `＋` → `+`、`３` → `3`）；
- 乘号 `×`、除号 `÷`、各类负号横线（`−`、`–`、`—`）分别按 `*`、`/`、`-` 处理；
- **所有空格会被去除**，怎么加空格都不影响；
- 公式编辑器插入的 LaTeX 自动转纯文本：`\frac{3}{4}` 视同 `3/4`、`\sqrt{3}` 视同 `√3`、`\times` 视同 `*` 等；
- 整式 / 因式分解类额外忽略大小写，`x²` 与 `x^2` 等价。

### 各题型判定标准

| 题型 | 标准答案形态 | 判定规则 |
| --- | --- | --- |
| 口算 / 四则巧算 | 数值 | 数值相等即对（容差 10⁻⁶）；支持 `a/b` 分数写法 |
| 一元一次方程 | 数值（题干已印出 `x=`） | 只填 x 的值，数值相等即对 |
| 一次不等式 | `x>3` 形态 | 解集方向与边界都须一致；`3<x` 翻转书写等价；`>=`、`<=`、`=>`、`=<` 均视同 ≥、≤ |
| 一次不等式组 | 区间或联立条件 | 解集完全一致才对：无解可写「无解 / 空集 / ∅」；区间开闭须一致；`(2,5)`、`2<x<5`、多条 `x>2 且 x<5`（用 且 / 逗号 / 分号分隔，自动取交集）、带 `x∈` 前缀均接受 |
| 一元二次方程 | 两根 | **根的集合等价、顺序无关**：`x1=2 或 x2=3` 的前缀可省略，「或 / 且 / 逗号 / 分号」分隔均可；根支持整数、小数、分数及 `√b`、`a√b`、`a±√b` 型无理数 |
| 一次方程组 | `x=…,y=…`（三元含 z） | 按未知数逐一比对数值，**书写顺序无关**；每个未知数的值都相等即可 |
| 三角函数 | 特殊角函数值 | 按**数值等价**判定：`√3/2`、`sqrt(3)/2`、公式编辑器的 `\frac{\sqrt{3}}{2}` 等任意等值写法均可；分子分母允许括号包裹 |
| 整式 / 因式分解 | 代数表达式 | 归一化后字符串全等，或代入 `x=0/1/2` 三点数值全部相等即对；隐式乘法自动识别（`2x` 视同 `2*x`、`(x+1)(x-2)` 自动补乘号）；含 sin/cos/tan 的整式按系数精确比对（`sinα`、`sina`、`\sin\alpha` 记号互通）；答案含除号的在多个整数点做恒等采样 |

::: tip 分数怎么写
`3/4` 与公式编辑器的 `\frac{3}{4}` 均可；在按数值比较的题型里，`0.75` 这样的等值小数同样有效。
:::

### 会判错的情况

- 该题**未作答**（留空提交）；
- 输入无法解析为该题型接受的形态（如数值题填了文字）；
- 不等式方向不同（且并非翻转书写）、区间开闭不一致；
- 二次方程少写或多写一个根；
- 方程组漏掉某个未知数的取值。

::: warning 无过程分
计算专区为全自动判分，只看最终结果，不批改解题步骤。需要步骤批改请使用题目作答（人工 / AI 批改）。
:::

## 七、练习统计

「计算」页面提供分类统计：

- **总题量 / 答对数 / 正确率**。
- **今日练习 / 今日答对 / 今日正确率**：当天表现一目了然。
- **按题型分类**各自的题量、答对数与正确率，帮助你定位计算领域中的短板分类。

## 八、补充：内置于组卷

计算题不仅能在线刷练，还**作为「计算题组」参与组卷**（见[组卷详解](/basic/paper)）：可按分类 / 难度 / 题量在试卷中加入一个「计算题组」，系统按固定种子生成相同的一批计算题并渲染进 PDF，适合制作口算卷、计算卷。

::: warning 无需重复贡献
计算专区的十类题型均由系统**自动出题、自动批改**，已覆盖对应知识点的完整支持。因此这类题目**不需要也不接受**通过「贡献题目」重复提交到题库（见[题目与题单规范](/academic/problem)）。请直接在计算专区练习，或通过组卷生成相应计算题组。
:::
