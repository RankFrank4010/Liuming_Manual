# 计算专区详解

计算专区是为小学、初中计算能力训练设计的专项练习：**系统自动出题、自动批改**，无需人工判分，适合反复刷练口算与基础计算。

## 一、九类计算题型

覆盖以下九类题目，对应不同年级的运算训练：

| 分类 | 说明 |
| --- | --- |
| 口算 | 简单的口算加减乘除 |
| 四则巧算 | 运用运算律的巧妙计算 |
| 整式 | 整式运算 |
| 一元一次方程 | 一元一次方程求解 |
| 因式分解 | 因式分解练习 |
| 一次不等式 | 一次不等式求解 |
| 一次不等式组 | 一次不等式组求解 |
| 一元二次方程 | 一元二次方程求解 |
| 一次方程组 | 一次方程组求解 |

::: tip 小数、分数计算去哪了？
小数与分数不再作为独立题型，而是作为**计算选项**叠加在其他题型上（见下文「选项」）。选择对应选项后，题目的数字就可以包含小数或分数。
:::

## 二、选项

部分题型支持额外的数字选项，用来调节题目数字的取值范围：

- **允许负数**：数字可为负数。
- **允许小数**：数字可为小数（如 1.25）。
- **允许分数**：数字可为分数（如 3/4）。
- **允许无理数**：数字可为无理数（如 √2）。

不同题型支持的选项不同，以页面显示为准。

## 三、难度

每个分类都支持三档难度：

- **简单**
- **中等**
- **困难**

难度用于控制题目的系数大小、运算步骤与复杂度。

## 四、生成一组题

1. 选择**分类**与**难度**。
2. 选择**题量**：10 / 20 / 30 道。
3. 系统生成一组题目并一次性展示。

**同一套题可复现**：每组题都带有一个固定「种子」，用它再生成一次会**得到完全相同的一组题**，因此可以：

- 重复刷练同一套题以强化记忆；
- 多人用同一套题做对比练习。

::: tip 怎么和别人做同一套题？
想要和同学对比，只需双方选择相同的分类、难度并生成同一批题（题量一致），就能得到完全相同的一组题进行同场对比。
:::

## 五、自动批改与结果反馈

作答完成后提交，系统对全组逐题批改：

- 逐题返回**是否正确**及其**标准答案**。
- 汇总：**总题数、答对数、正确率（整数百分比）**。

批改会记录用时与结果，纳入**我的计算练习统计**。

## 六、练习统计

「计算」页面提供分类统计：

- **总题量 / 答对数 / 正确率**。
- **今日练习 / 今日答对 / 今日正确率**：当天表现一目了然。
- **按九类分类**各自的题量、答对数与正确率，帮助你定位计算领域中的短板分类。

## 七、补充：内置于组卷

计算题不仅能在线刷练，还**作为「计算题组」参与组卷**（见[组卷详解](/basic/paper)）：可按分类 / 难度 / 题量在试卷中加入一个「计算题组」，系统按固定种子生成相同的一批计算题并渲染进 PDF，适合制作口算卷、计算卷。

::: warning 无需重复贡献
计算专区的九类题型均由系统**自动出题、自动批改**，已覆盖对应知识点的完整支持。因此这类题目**不需要也不接受**通过「贡献题目」重复提交到题库（见[题目与题单规范](/academic/problem)）。请直接在计算专区练习，或通过组卷生成相应计算题组。
:::
