# 计算专区详解

计算专区是为小学、初中计算能力训练设计的专项练习：**系统自动出题、自动批改**，无需人工判分，适合反复刷练口算与基础计算。

## 一、七类计算题型

覆盖以下七类题目，对应不同年级的运算训练：

| 分类 | 说明 |
| --- | --- |
| 口算 | 简单的口算加减乘除 |
| 四则巧算 | 运用运算律的巧妙计算 |
| 整式 | 整式运算 |
| 小数计算 | 小数的四则运算 |
| 分数计算 | 分数的四则运算 |
| 一元一次方程 | 一元一次方程求解 |
| 因式分解 | 因式分解练习 |

## 二、难度

每个分类都支持三档难度：

- **简单**
- **中等**
- **困难**

难度用于控制题目的系数大小、运算步骤与复杂度。

## 三、生成一组题

1. 选择**分类**与**难度**。
2. 选择**题量**：10 / 20 / 30 道。
3. 系统生成一组题目并一次性展示。

**同一套题可复现**：每组题都带有一个固定「种子」，用它再生成一次会**得到完全相同的一组题**，因此可以：

- 重复刷练同一套题以强化记忆；
- 多人用同一套题做对比练习。

::: tip 怎么和别人做同一套题？
想要和同学对比，只需双方选择相同的分类、难度并生成同一批题（题量一致），就能得到完全相同的一组题进行同场对比。
:::

## 四、自动批改与结果反馈

作答完成后提交，系统对全组逐题批改：

- 逐题返回**是否正确**及其**标准答案**。
- 汇总：**总题数、答对数、正确率（整数百分比）**。

批改会记录用时与结果，纳入**我的计算练习统计**。

## 五、练习统计

「计算」页面提供分类统计：

- **总题量 / 答对数 / 正确率**。
- **今日练习 / 今日答对 / 今日正确率**：当天表现一目了然。
- **按七类分类**各自的题量、答对数与正确率，帮助你定位计算领域中的短板分类。

## 六、补充：内置于组卷

计算题不仅能在线刷练，还**作为「计算题组」参与组卷**（见[组卷详解](/basic/paper)）：可按分类 / 难度 / 题量在试卷中加入一个「计算题组」，系统按固定种子生成相同的一批计算题并渲染进 PDF，适合制作口算卷、计算卷。
