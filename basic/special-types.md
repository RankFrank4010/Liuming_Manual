# 特殊题型使用指南（阅读理解 / 小猫钓鱼）

**阅读理解**（语文）与**小猫钓鱼**（英语选词填空）是两类特殊的自动判分题型：前者靠「文章 + 子题」，后者靠「文章 + 词库空位」。它们的出题与作答方式与普通题不同，本页分别讲**怎么出题、怎么作答、怎么判分**。

## 一、阅读理解（语文）

### 1.1 怎么出题

1. 在「贡献题目」中，**学科选「语文」**，**题型选「阅读理解」**。
2. 在**题干**中填写**文章正文**。
   - 文章排版**自动居中**（与 PDF 导出一致）。
   - 文章支持两种标记：`++文字++` 加**划线**、`==文字==` 加**加点（着重号）**。
3. **必须配置小题**：阅读理解必须包含小题（文章 + 子题提问）。为每个小题填写：
   - 小题题干（提问）；
   - 小题题型（如选择、填空、简答）；
   - 小题答案。
4. 保存并提交，走正常审核流程。

### 1.2 怎么作答

- 学生看到**居中的文章**，按其下的各个**小题**逐个作答、逐个提交。

### 1.3 怎么判分

- 阅读理解**顶层没有标准答案**，判分**委托给各小题**：
  - 客观小题（选择 / 填空等）由系统**自动判分**；
  - 主观小题转入[批改](/basic/grading)。
- **逐小题独立判分**，互不影响。

## 二、小猫钓鱼（英语选词填空）

### 2.1 怎么出题

1. 在「贡献题目」中，**学科选「英语」**，**题型选「小猫钓鱼」**。
2. 在**题干**中填写**文章**，用以下任一写法标出**空位**：
   - `____`：4 个及以上连续下划线 → 按出现顺序自动编号；
   - `___36___`：3 个及以上下划线夹 1~3 位数字（上海卷样式）→ 用该数字作为空位编号。
3. 在**「词库选项」**中逐条填写词库（**每个选项一个词 / 短语**）。词库会显示在**文章正上方的方框**内供选词填空。
   - 可用**「十一选十」「五选四」**预设快速生成一批选项；也可「添加选项」「删除末项」手动增删。
4. 在**「每空标准答案」**中逐空填写答案。系统会校验「标准答案数」与「文章空位数」是否一致，不一致会提示补齐。

### 2.2 怎么作答

1. 文章**上方**是**词库方框**，每个词带字母编号（A / B / C …）。
2. **点词库里的词** → 自动填入**第一个空位**；词库中已用过的词会置灰。
3. **点已用过的词** → **撤回**它所在空位的作答。
4. **点文章里已填的空位** → **清除**该空。
5. 空位默认显示编号；填入后显示所选字母。

### 2.3 怎么判分

- 系统**自动判分**：按**空位出现顺序逐空比对**，全部匹配即判对。
