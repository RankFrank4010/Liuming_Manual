# 家长监护详解

家长监护让家长可以**绑定孩子账号**，以「家长」视角查看孩子的学习数据与状态，并借助 AI 分析获得针对性建议，即使孩子专注学习也能让家长安心。

## 一、绑定孩子（监护关系）

监护由孩子**邀请授权**给家长，单向建立「被监护人 → 监护人」关系：

- **发起绑定**：孩子（学生账号）在绑定页面输入家长的**昵称 + 邮箱**发起监护邀请。
- **家长接受**：家长账号可在「监护请求」中接受 / 拒绝该绑定请求。
- **身份核对**：绑定建立时会核对家长所填写的孩子关系（如邮箱），确认监护关系真实有效。
- **解除 / 管理**：家长解绑、更换孩子，或被监护的学生解除绑定。

::: note 需要孩子同意
监护关系必须由孩子**主动发起授权**，家长无法单方面绑定他人账号；这样能保证孩子的隐私与自主。
:::

## 二、查看学习数据

绑定后，家长在「家长中心」可切换查看每**受监护孩子**的维度化数据：

- **总统计**：总提交数、正确 / 错误数、正确率（百分比）。
- **今日数据**：今日提交 / 今日正确 / 正确率。
- **学科维度**：各**学科**的提交数、正确数与正确率。
- **知识点维度**：各**知识点标签**的提交数、正确数与正确率，定位孩子擅长 / 薄弱的具体知识点。
- **按天 / 按学科 / 按标签**可切换查看每日变化趋势。

## 三、AI 分析

家长端提供 **AI 学习分析**：

- 系统根据与孩子学习最相关的统计数据（总体、今日、学科维度、知识点维度）生成提示词，调用 AI 输出**孩子近期学习表现分析与针对性建议的报告**。
- 帮助家长快速抓住：哪门功课薄弱、哪些知识点需重点补强、如何改进。

> AI 分析为辅助参考；家长仍可结合[学习数据](/basic/practice-stats)（错题本、知识图谱）自行判断。

## 四、监护操作

- **多孩管理**：一个家长可同时监护多个孩子，切换查看各自的独立数据。
- **展示切换**：家长中心内切换「孩子 · 数据视图」查看不同维度。
