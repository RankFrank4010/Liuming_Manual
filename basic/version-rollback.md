# 版本回退详解

版本回退是流明平台为题目提供的历史版本恢复功能，支持将已发布题目回退到任意历史版本。

## 一、功能概述

版本回退提供以下核心功能：

- **历史版本查看**：查看题目的所有历史版本。
- **版本对比**：对比不同版本的内容差异。
- **一键回退**：将题目恢复到指定历史版本。
- **回退记录**：记录所有回退操作，确保可追溯。

## 二、使用场景

### 2.1 内容纠错

当发现当前版本存在错误，但历史版本正确时，可回退到正确版本。

### 2.2 误操作恢复

当误修改或误删除题目内容时，可回退到修改前的版本。

### 2.3 版本管理

通过版本回退功能，可灵活管理题目的历史版本。

## 三、操作流程

### 3.1 查看历史版本

1. 在题目详情页点击「版本历史」标签页。
2. 查看所有历史版本列表。
3. 点击任意版本可查看该版本的完整内容。

### 3.2 版本对比

1. 在版本历史页面选择两个版本。
2. 点击「对比」按钮。
3. 系统高亮显示内容差异。

### 3.3 执行回退

1. 在版本历史页面选择要回退到的版本。
2. 点击「回退到此版本」按钮。
3. 确认回退操作。
4. 系统创建新版本，内容为所选历史版本。

## 四、回退规则

### 4.1 版本创建

回退操作会创建一个**新版本**，而不是直接修改当前版本：
- **保留历史**：原版本保留，不被删除。
- **新版本内容**：新版本内容与所选历史版本完全一致。
- **版本号递增**：新版本号在当前最大版本号基础上递增。

### 4.2 状态变化

回退后题目状态可能变化：
- **已发布 → 待审核**：如果回退到的版本从未审核通过。
- **已发布 → 已发布**：如果回退到的版本已审核通过。
- **需再次审核**：管理员可要求回退后重新审核。

### 4.3 权限要求

以下角色可执行回退操作：
- **管理员**：可回退任意题目到任意版本。
- **创建者**：可回退自己创建的题目。
- **贡献者**：可回退自己贡献的题目（需审核通过）。

## 五、回退记录

所有回退操作都会记录：
- **操作者**：执行回退的用户。
- **操作时间**：回退操作的时间。
- **目标版本**：回退到的历史版本号。
- **操作原因**：回退原因说明（可选）。

## 六、注意事项

- **不可逆操作**：回退操作本身不可逆，但可再次回退到其他版本。
- **内容完全一致**：回退版本内容与历史版本完全一致，包括附件。
- **审核状态**：回退后可能需要重新审核。
- **统计保留**：历史统计数据保留，不受回退影响。
