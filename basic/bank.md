# 题库详解

题库是流明的核心。所有题目由社区用户贡献，经管理员审核后发布，供全站用户练习与引用。

## 学科体系

题库覆盖**九大主科**，其中理科细分了子学科：

| 主科 | 子学科 |
| --- | --- |
| 数学 | 代数、几何、微积分、概率、数论、组合、分析、其他 |
| 物理 | 物理、力学、热学、声学、光学、电磁、物理其他 |
| 化学 | 化学、无机、有机、物理化学、分析、结构 |
| 生物 | （保留子学科体系） |
| 地理 | 自然地理、人文地理、其他 |
| 历史 | 中国古代史、中国近代史、中国现代史、世界古代史、世界近代史、世界现代史 |
| 中文 / 英语 / 政治 | 无子学科 |

- 数学、物理、化学、生物、地理、历史保留子学科层级；语文 / 英语 / 政治为单层。
- 学科体系由管理端动态配置（每个学科可设定题号前缀、允许学段、评分基准等），前端会动态加载，因此新增学科无需改动代码。

## 二、题型

支持的题型根据学科区分（不同学科可用题型不同）：

- **数学**：填空题、选择题、等价表达式、判断题、证明题、应用题
- **物理**：填空题、选择题、等价表达式、判断题、证明题、应用题、简答题
- **化学**：填空题、选择题、等价表达式、判断题、应用题、简答题
- **生物**：选择题、填空题、判断题、应用题、简答题
- **语文 / 英语**：选择题、填空题、简答题（回答问题）、作文
- **地理 / 历史**：选择题、填空题、判断题、简答题（历史含作文）
- **政治**：选择题、填空题、判断题、简答题、作文、应用题

选择题支持**单选 / 多选 / 不定项**三种模式。英语科目支持**听力题**（题干 + 听力音频 + 听力材料）。

## 二、学段与难度

- **学段**：题目分为小学低年级、小学高年级、初中、高中。物理、化学、地理、历史、政治不设小学学段。
- **难度星级**（提交题目时选择）：两套体系——
  - **基础星级**：送分、简单、中档、难、极难。
  - **竞赛星级**：竞-、竞、竞+ 为各科共用入门档；理科按本学科奥赛体系命名（数学 CMO/IMO、物理 CPhO/IPhO、化学 CChO/IChO、生物 CBO/IBO），非理科为 国-、国、国家队。
  - 各档星级的判定标准（含各学科学段锚点）见[难度星级判定标准](/academic/difficulty)。

### 动态难度评分（Rating）

除提交时选择的难度星级外，每道题还带有一个**动态数值评分**（范围 100–3500），反映题目经社区实际练习后的真实难度：

- **基础值**：由学科配置的「学段基准 + 难度星级增量」得到，例如某学段基准 500 分，标为「难」再加若干分。
- **动态调整**：累计提交达到阈值后，根据实际正确率调整——正确率偏高（偏简单）则降低评分，偏低（偏难）则提高评分。
- **置信度权重**：提交越多，调整参考越可靠，评分越稳定可信。
- **幅度上限**：单次调整设置上限，避免评分剧烈波动。

因此你可以按动态评分的升 / 降序排序，找到「由真实答题数据校准过」的易 / 难题。

## 三、检索与筛选

题库列表支持多维组合筛选：

- **关键词**：按标题或题号模糊匹配。
- **科目**：可多选；支持**严格模式 / 任意模式**——严格模式要求题目同时覆盖所选全部科目，任意模式命中任一即可。
- **题型 / 学段 / 难度星级**：均支持多选。
- **标签**：任意标签命中即可，并支持标签云（按热门程度排序）。
- **动态评分区间**：按动态评分的数值范围筛选。
- **听力题**：只看听力题。
- **排序**：默认按发布时间，可切换为按动态评分升 / 降序。

::: tip 关于子学科
筛选物理时，它的子学科（力学、光学等）标签与题目也能被同时命中，无需分别筛选。
:::

## 四、题号（Code）

每道题有唯一题号，格式为「学科前缀 + 4 位数字」，如数学 `M0001`、化学 `C0002`、物理（力学）`J0001` 等。题号由系统按当前最大序号自动生成，作为**组卷**、引用与交流的稳定标识。

## 五、收藏

登录后可将题目加入收藏，支持添加 / 移除 / 查询是否已收藏。收藏列表可在「个人中心 → 收藏」查看与检索，方便集中回顾常做的题目。

## 六、贡献题目

任何人都可以为社区贡献题目（路径：导航「贡献题目」）。

::: warning 计算专区已覆盖的题目不接受
计算专区已覆盖的口算、四则巧算、整式、一元一次方程、因式分解、一次不等式、一次不等式组、一元二次方程、一次方程组九类计算题，系统**自动出题、自动批改**，无需重复贡献到题库。此类题目提交后将被**审核拒绝**（详见[题目与题单规范](/academic/problem)与[计算专区详解](/basic/calc)）。
:::

### 填写内容

- **标题、学段、难度星级、科目/子学科、题型**。
- **题干**：支持 Markdown 文本（理科自动启用**可视化输入公式**，支持图形化拼搭 LaTeX 公式、图片附件；编辑器用法见[输入与编辑器详解](/basic/editor)）。
- **答案**：选择主观 / 客观题型填写相应答案（详见[自动判题详解](/basic/judge)）。
- **题解**：可选的解析过程。
- **标签**：可选知识点标签（可提案新标签）。
- **听力题**（仅英语）：勾选听力题，填写听力材料，并上传听力音频（仅音频格式，最大 50MB）。

> **题解可以是图片**：附件分为「题干配图 / 插图 / 题解图」等用途（`purpose`），其中**题解用途的图片**会作为本题的题解展示（题解既可以是文字解析，也可以是一张图）。

某些可选内容（题解 / 答案 / 听力材料）若确实无法提供，可显式标记为「缺失」，交由审核判断。

### 提交与审核流程

1. 提交后题目状态为 **待审核（pending）**，系统自动生成题号，并登记工作单。
2. 管理员在「审核台」审核：**通过 → 发布（published）**，或 **拒绝** 并填写拒绝原因。
3. 已发布的题目标记为可被练习。你的「我的贡献」页面可查看已通 / 被拒状态及拒绝原因。
4. 修改题目（更新内容、上传听力音频）后，题目会**重新回到待审核状态**，需再次审核。
5. 审核操作全程记录（审核人、时间、原因），可追溯。

### 修改意见（新版本任务）

对已发布的题目，除直接修改外，还可提交「修改意见」（完整的新版本），同样走审核流程。审核通过后替换线上题目；题目的历史修改意见可查看与追溯。

## 七、审核

**审核台**（admin 专属）：

- **待审核题目**：列出所有 pending 题目，含题干、答案、题解、附件、听力材料。审核通过或拒绝（附原因）。
- **审核记录**：每道题的完整审核日志（操作、操作者、时间、原因）。
- **新版本审核**：审核用户提交的题目修改意见。
- 审核题目时同样会联动工作台 / 工单系统记录。

## 八、安全边界

- **匿名浏览**：未登录用户可浏览公开题库，但浏览行为会受到必要的访问限制，登录后即可正常使用全部功能。
- **答案解锁**：题目答案与题解默认**不直接暴露**给练习用户，需通过提交解锁（见[自动判题与解锁](/basic/judge)）。
- **组卷附带题解**：按题号批量查询时，仅管理员可请求附带标准答案与题解，避免绕过解锁机制。

## 九、AI 题解

部分题目在**解锁答案后**，答案区下方会提供**AI 生成的题解**（由 AI 依据题目、参考答案与标准题解生成的一份 Markdown 解析）：

- 仅**已解锁**的题目会展示 AI 题解区。
- **贡献者本人或管理员**可一键**生成 / 重新生成**某题的 AI 题解。
- 当题目标答 / 题解内容更新后，旧 AI 题解会标记为「待更新」，可重新生成以同步。

> AI 题解为辅助参考，与「AI 批改」共用 AI 配置；是否启用由管理端统一控制（见[账户与安全 · 管理后台](/basic/account-safety#五、管理后台)）。
