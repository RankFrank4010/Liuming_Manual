# 注册与登录

流明支持**多种登录方式**：你可以用**用户名 + 密码**登录，也可以用**手机号 + 短信**验证，还可以启用 **Passkey**（指纹 / 面容免密登录）或 **OTP**（动态验证码）等更便捷、更安全的方式。你可以只使用其中一种，也可以同时绑定多种，按自己习惯任选。

::: tip 多种方式任选其一
注册时需要用手机号发送一条短信完成验证；注册成功后，只要配置得当，日常登录可以完全**不用再发短信、也不产生短信费用**：用**密码**登录最省事，想一键免密启用 **Passkey**，想更安全再开启 **OTP** 两步验证。手机号短信登录主要作为备用方式（忘记密码、换设备时使用）。所有方式都指向同一个账号，互不冲突。
:::

本页面向第一次使用流明的新用户，逐步骤讲解如何注册、登录、修改手机号、管理登录方式，以及使用过程中需要注意的安全事项。如果你在操作中遇到问题，可以先查看文末的[常见问题（FAQ）](#常见问题faq)，多数疑问都能在那里找到答案。

## 简介

流明的账号体系非常直观，可以概括为一句话：

> **一个账号，多种方式。手机号是账号的根基。**

这句话包含两层意思：

- **注册一次，方式自选**。注册时创建你的账号（用户名 + 密码），并绑定手机号；之后按你的习惯选择密码、短信、Passkey 或 OTP 中的任意方式来登录。
- **手机号是账号的归属证明**。手机号是找回账号、验证身份、修改登录方式时最重要的凭证，请务必使用**自己名下**的真实手机号。

::: tip 为什么短信登录需要"主动发送"？
流明的短信登录与常见网站相反：**不是等你接收验证码，而是需要你用手机主动发送一条短信**。这样做是为了**防止一次性手机号批量注册机器人账户**——接码平台等提供的一次性号码大多只能接收短信、无法主动发送，因而无法完成验证，从源头上挡住了批量注册。对正常用户来说，只要用自己的手机按页面提示发一条短信即可，过程很简单。
:::

### 登录方式一览

| 方式 | 怎么登录 | 适合场景 |
| --- | --- | --- |
| **用户名 + 密码** | 输入用户名 / 手机号和密码 | 日常登录，最常用 |
| **手机号 + 短信** | 用手机主动发送一条短信完成验证 | 忘记密码、换设备、备用 |
| **Passkey** | 指纹 / 面容 / 设备 PIN 一键确认 | 免密快捷登录，方便又安全 |
| **OTP** | 密码 / Passkey 登录后，再输入身份验证器 App 的 6 位动态码 | 二次验证，为登录额外加一道安全锁 |

每种方式的详细步骤见下文对应章节。

## 注册（首次使用）

首次注册有两种途径，任选其一即可：

- **方式一：手机号注册（推荐）**：输入手机号，按提示用手机主动发送一条短信，验证通过后设置用户名和密码，即完成注册。这种方式同时绑定了手机号，后续找回密码、更换登录方式都更方便。
- **方式二：用户名密码注册**：直接设置用户名和密码完成注册；建议随后绑定手机号（见[修改手机号](#修改手机号)），用于日后找回账号与增强安全。

下面以**方式一（手机号注册）**为例，给出完整的分步流程。

### 第一步：进入注册页

- 打开流明网站首页，点击页面右上角的**注册**按钮；也可以先点**登录**，再在登录页切换到"注册"。
- 在注册页面选择**手机号注册**，进入手机号验证界面。

::: tip 从功能页被引导到注册页？
如果你是从某个具体功能被引导来的（例如打开题目、参加比赛、查看作业），流程完全一样。注册登录成功后会自动跳转回你刚才想访问的页面，不会丢失操作。
:::

### 第二步：输入手机号

- 在输入框中**填写你的手机号**，请确保号码正确、没有多余的空格，也不要混入其他符号。
- 中国大陆手机号直接填写 **11 位号码**即可（例如 `13800000000`），无需手动添加国家区号。
- 如果手机号带有区号信息，请按照页面提示的格式填写；不确定时先按 11 位号码输入。

::: danger 请勿输入他人号码
账号与手机号一一对应。输入他人的手机号将无法完成验证，因为这条短信只能从你填写的号码发出。请务必输入**自己**的手机号。
:::

### 第三步：确认手机号

- 提交手机号后，系统会**回显格式化后的手机号**供你核对。例如你输入 `13800000000`，页面上会以更易读的分组形式展示出来。
- 请仔细核对每一位数字，确认无误后再进入下一步。
- 如果发现号码不对，点击**返回**或**修改**，重新输入即可，不会产生任何后果。

::: tip 为什么要再确认一次？
这一步是为了防止手误输错号码。系统只会认可**从你填写的号码发出的短信**，一旦号码填错，后面的短信就白发了。多花三秒钟核对，能省去后面一整轮操作。
:::

### 第四步：发送短信

- 确认号码后，页面会显示一条**发送指令**：请用手机 **`138****0000`**（就是你刚填写的号码）发送短信到某个指定号码，短信内容可能是几串字符或一个一次性口令。
- 拿出手机，打开短信应用，**新建一条短信**：收件人填页面上显示的指定号码，内容填页面要求发送的字符，然后**发送**。
- 发送后，页面会自动检测。请保持页面打开，不要关闭，等待平台确认收到你的短信。

::: warning 关于短信费用
这条短信由**你的手机按正常短信资费发出**，会消耗你手机套餐内的短信条数（或按条计费，通常不足一毛钱）。发送一次即可，平台不会要求你反复发送。
:::

::: tip 发送后要做什么？
发完短信后什么都不用做，保持页面打开等待即可。平台收到短信后会**自动完成验证**，通常几秒到十几秒内就会跳转到下一步。如果等待超过一两分钟没有反应，可以按页面提示重新发起，或在文末[常见问题](#常见问题faq)中查找解决办法。
:::

### 第五步：设置用户名与密码

验证通过后，进入账号设置环节：

- **用户名**：设置一个便于同学、老师辨认的称呼，之后用于密码登录。社区中大家看到的就是这个名字，请谨慎选择，避免使用违规或容易引起争议的内容。
- **密码**：设置你的登录密码，建议使用**长度足够、包含字母与数字**的密码，不要与其他网站共用。密码用于日常登录（见[密码登录](#方式一密码登录用户名--密码)）。

### 第六步：完善个人资料

注册流程的最后一步，系统会引导你完善个人资料：

- **身份 / 学段**：选择你的年级（小学低年级、小学高年级、初中、高中）。这决定了你的学习画像，也影响题目推荐与学段筛选的默认值。
- **头像**：可选。设置头像能让大家更容易认出你，不设置也可以正常使用。

::: tip 资料随时可以修改
首次完善资料只是为了更好的体验，跳过或之后在**账户设置**中修改都可以。涉及账号信息的细节，见[账户与安全详解](/basic/account-safety)。
:::

::: tip 注册完成！
完成以上步骤后，你就正式成为流明的一员了。接下来可以先去[功能介绍](/basic/features)看看平台能做什么，或者直接打开一道题，开始第一次练习。社区里的交流与讨论，欢迎去[讨论区](/policies/rule)了解规则后参与。
:::

::: tip 之后登录可以不花钱
注册时发送短信验证是**一次性必要操作**（用于核实你的手机号真实有效）。注册成功后，只要使用**用户名 + 密码**或 **Passkey** 登录，日常就不再需要发送短信、也不会产生任何短信费用；短信登录只在你忘记密码、更换设备等备用场景使用。建议注册后尽快用密码登录一次，熟悉日常登录方式。
:::

### 注册阶段小结

| 步骤 | 你要做什么 | 关键点 |
| --- | --- | --- |
| 进入注册页 | 点击右上角**注册** | 手机号注册或用户名密码注册 |
| 输入手机号 | 填写 11 位手机号 | 一定是自己的号码 |
| 确认手机号 | 核对回显号码 | 填错会导致短信白发 |
| 发送短信 | 按页面指令发出短信 | 收件人、内容与页面一致 |
| 设置用户名与密码 | 创建你的账号名与密码 | 密码用于日常登录 |
| 完善资料 | 设置学段、头像 | 之后可随时修改 |

### 注册时可能遇到的提示

| 提示信息 | 含义 | 该怎么做 |
| --- | --- | --- |
| "短信内容不正确" | 发送的短信内容与页面要求不一致 | 按页面显示的字符重新发送 |
| "短信发送号码不正确" | 收件人号码填错 | 按页面显示的号码重新发送 |
| "验证超时，请重试" | 等待超时或短信未送达 | 按页面提示重新发起 |
| "发起过于频繁" | 短时间内发起次数太多 | 等待一段时间后再试 |
| "手机号已注册" | 该号码已有账号 | 按登录流程直接登录 |
| "用户名已存在" | 该用户名已被占用 | 换一个用户名 |
| "请输入正确的手机号" | 号码格式不对 | 检查位数与是否有空格 |

如果遇到上表之外的提示，请按页面文字说明操作，或在讨论区发帖询问。

## 登录

流明支持多种登录方式，选你最方便的一种即可。所有方式都登录同一个账号。

### 方式一：密码登录（用户名 + 密码）

日常最常用的方式：

1. 打开流明网站，点击右上角**登录**按钮。
2. 在登录页输入你的**用户名**（或绑定的**手机号**）和**密码**。
3. 点击登录，验证通过即进入平台。

::: tip 忘记密码怎么办？
如果忘记密码，可以在登录页选择"忘记密码"，通过绑定的**手机号发送短信**验证身份后重设密码。前提是你注册时绑定了手机号，所以注册后建议尽快绑定。
:::

### 方式二：手机号 + 短信登录

当你不方便使用密码（忘记密码、换设备、公共场合不方便输密码）时使用：

1. 在登录页选择**手机号登录**。
2. 输入你的手机号，核对回显号码无误。
3. 按页面显示的指令，用该手机号**主动发送一条短信**到指定号码（内容见页面提示）。
4. 保持页面打开，等待平台确认收到短信，验证通过即登录成功。

::: tip
整个过程通常不到 **30 秒**。只要手机在身边、信号正常、能发短信，登录非常快。这也是忘记密码时找回账号的主要途径。
:::

### 方式三：Passkey 登录（免密）

如果你已经启用 Passkey（通行密钥），可以在登录页选择 **Passkey 登录**：

1. 点击**使用 Passkey 登录**（或"使用通行密钥"）。
2. 按系统提示完成本机验证——通常是**指纹、面容识别**，或输入**设备 PIN 码**。
3. 验证通过即完成登录，无需输入密码或短信。

::: tip Passkey 是什么？
Passkey（通行密钥）是一种**免密登录**方式：把你的设备（手机 / 电脑）本身当作"钥匙"，用指纹、面容或设备 PIN 确认身份。它比密码更快捷，也更难被窃取。启用方法见[管理登录方式](#管理登录方式)。
:::

### 方式四：OTP 二次验证（额外安全锁）

OTP（一次性密码）**不能单独用于登录**，它只作为**二次验证**：在密码（或 Passkey）登录之后，再额外输入一次身份验证器 App 生成的动态码，为登录多加一道安全锁。

开启 OTP 后，密码登录的流程变为两步：

1. 输入用户名和密码，验证通过。
2. 打开你绑定的**身份验证器 App**（如 Google Authenticator、Microsoft Authenticator 等），查看当前显示的 6 位动态码并输入。
3. 两道验证都通过后，才完成登录。

::: tip OTP 适合谁？
OTP 适合对账号安全要求较高的用户。即使密码泄露，没有动态码也无法登录你的账号。启用方法见[管理登录方式](#管理登录方式)。
::: danger 关于恢复码
开启 OTP 时，请务必**妥善保存页面提供的恢复码 / 备用码**。更换手机或误删验证器 App 时，恢复码是找回账号的唯一途径；丢失恢复码又无法登录，账号可能无法找回。
:::

### 登录的常见情形

- **换了一台设备**：用手机号发短信，或用用户名 + 密码登录即可，登录数据都存在账号里，与设备无关。
- **换了一个浏览器**：同样是任意一种方式验证，登录后一切照旧。
- **很久没登录**：不影响账号与数据。再次登录后，练习记录、错题本、积分等都还在。

::: warning 在公用设备上登录
如果是在教室电脑、机房、公共图书馆等公用设备上登录，请在离开前**登出账号**，并且不要勾选"记住我"之类的选项。公用设备的安全注意事项详见下文[账号安全提醒](#账号安全提醒)。
:::

## 登录之后

登录成功后，你就拥有了流明账号的全部能力。下面是你登录后最先接触到的几个入口：

- **个人主页**：点击右上角头像即可进入。这里展示你的练习热力图、提交记录、近期练习、收藏与错题，也是他人查看你公开档案的入口。
- **账户设置**：在个人菜单中可以找到。这里维护你的**身份 / 学段**、**编辑器模式**（可视化模式还是代码模式）等个人配置。
- **账户中心**：手机号修改、密码修改、Passkey / OTP 管理都在这里完成。
- **讨论区**：登录后才能发帖、回复与参与社区讨论。发言请遵守[社区规则](/policies/rule)。

::: tip 这些入口都在哪里？
不同页面右上角的头像或昵称菜单是统一入口。登录后第一件事，可以先逛逛这个菜单，熟悉各项功能的位置。
:::

### 登录状态的常见疑问

- **登录状态会持续多久**：登录状态在有效期内会自动续期，只要你经常使用，基本不会感到需要重新登录。
- **换浏览器是否掉登录**：会的。登录状态与浏览器相关，换一个浏览器或清除浏览器数据后，需要重新登录一次。
- **清除 Cookie 会不会丢数据**：不会。Cookie 只保存登录状态，账号数据都存在服务器上，重新登录后一切如初。

## 管理登录方式

在**账户中心 → 登录方式**中，你可以管理账号绑定的各种登录方式：

- **密码**：修改密码；建议使用**长度足够、字母与数字混合**的强密码，避免与其他网站共用。
- **手机号**：绑定 / 修改手机号（见下文）。手机号是找回账号的重要凭证，建议保持绑定。
- **Passkey**：添加或移除 Passkey。启用后，支持指纹 / 面容的设备可以一键免密登录；建议在常用设备（手机、笔记本）上各添加一个。
- **OTP**：启用或关闭 OTP（二次验证）。启用时需要先用身份验证器 App 扫描页面上的二维码，完成绑定；之后用密码（或 Passkey）登录时，还需再输入一次 App 生成的动态码。OTP 仅作为二次验证，不能单独用于登录。

::: tip 建议组合
- 追求**方便**：密码 + Passkey，日常指纹 / 面容一键登录。
- 追求**安全**：密码 + OTP 两步验证，或手机号短信作为备用。
- 无论怎么组合，都建议**绑定手机号**，它是找回账号的兜底凭证。
:::

## 退出登录

在公用设备（教室电脑、机房、图书馆电脑）使用完毕后，请务必退出登录：

### 操作步骤

- 点击页面右上角的**头像**，打开个人菜单。
- 在菜单底部找到**退出登录**（或"登出"），点击即可。
- 页面跳转回未登录状态即表示退出成功。

::: danger 公用设备务必登出
在公用设备上登录却忘记登出，等于把账号留给了下一位使用者。由此产生的违规行为，平台处理时以账号为准，不会因为你解释"不是我操作"而免责。离开前多看一眼，确认自己已退出登录。
:::

### 关于浏览器自动填充

- 公用设备上请**不要**让浏览器记住用户名、密码或手机号。
- 私人设备上，为方便起见可以允许浏览器保存登录信息，但请确保设备本身设置了锁屏密码。

## 修改手机号

当你更换了手机号，或希望改用另一个号码时，可以在**账户中心**里完成换绑，无需重新注册，也不会丢失任何数据。

### 第一步：进入账户中心

- 登录后，点击右上角你的**头像**或**昵称**，进入账户中心。
- 在账户信息区域中找到**手机号**一栏，点击**修改**或**更换手机号**。

### 第二步：确认身份

- 出于安全考虑，修改手机号前通常需要先验证当前身份（如输入当前密码，或按提示发送短信验证），确认是你本人在操作。
- 按页面提示完成验证。

### 第三步：输入新手机号

- 在弹出页面中**填写你想要绑定的新手机号**。
- 提交后核对系统回显的格式化号码，确保无误。

::: danger 新旧手机号的关系
修改手机号是**绑定关系的转移**，不是合并账号，也不是重新注册。你的练习记录、错题本、积分、收藏、团队等所有数据都会保留在原账号上，只是登录所用的手机号变为新号码。
请务必使用**自己名下**的新手机号。如果把号码换成别人的，等于把账号交给了别人，后果自负。
:::

### 第四步：用新手机号发送短信

- 页面会显示发送指令：请用**新手机号**发送短信到指定号码（内容见页面提示）。
- 拿出新手机，按页面指令**发送短信**。
- 平台收到短信并确认号码无误后，账号即完成换绑。

::: tip 短信用哪台手机发？
注意，这条短信要用**新手机号**发送，而不是旧手机号。请确认新手机就在手边、能正常发短信，再发起更换，避免卡在发送环节。
:::

### 第五步：完成更换

- 页面提示更换成功后，**以后请使用新手机号**进行短信登录或找回账号。
- 旧的手机号不再关联该账号。

::: warning 更换后的确认
更换完成后，建议立刻用新手机号完整走一遍登录流程，确认新号码可以正常使用。同时记住自己的账号数据（如昵称、UID），以备日后需要时核对身份。
:::

### 修改手机号的几种场景

- **换号了**：按上述步骤换绑到新号码，继续正常使用。
- **旧手机丢了**：若还能通过其他设备登录账号，先登录后立即修改手机号，避免新卡落入他人手中后账号被冒登。
- **旧号码已停机、无法验证**：在无法通过手机号验证的情况下，可以尝试用**用户名 + 密码**登录后修改；若连密码也遗忘，请在讨论区联系管理员说明情况，并尽可能提供账号信息（昵称、UID、常用设备等）以便核实身份。

### 修改手机号与家长监护的关系

- 如果你的账号已经与家长的账户建立监护关系，修改手机号**不会**解除监护关系。
- 修改手机号只改变登录凭证，学习数据与监护绑定关系都保持不变，详见[家长监护详解](/basic/guardian)。

## 账号安全提醒

账号安全需要你和平台共同维护。以下几点是底线，请务必记牢：

- **设置并保管好密码**。密码请使用**长度足够、字母与数字混合**的组合，不要与其他网站共用；不要在公用设备上让浏览器记住密码。
- **保管好自己的手机号**。手机号是找回账号、验证身份的根基，不要随意把实名手机号交给他人代为注册、代为登录，也不要借给他人使用。
- **启用 Passkey / OTP 更安心**。在常用设备上启用 **Passkey**，或开启 **OTP** 两步验证，能显著提升账号安全性（见[管理登录方式](#管理登录方式)）。
- **短信指令不要外泄**。使用手机号短信登录时，页面上显示的发送内容等同于临时口令，**不要转发给他人**。平台工作人员永远不会让你把短信指令发给别人。
- **不要使用自动填充与"记住我"**。在公用电脑上使用本站时，务必**不要**勾选记住登录状态，也尽量不要让浏览器自动填充信息，离开前记得**登出账号**。
- **被他人使用后果自负**。账号在公用设备上未登出而被他人使用并产生违规行为时，处理以账号为准，不接受"不是我操作的"之类的申诉理由。请守护好自己的登录状态。
- **发现异常及时处理**。如果怀疑账号被他人登录，请立即修改密码、在**账户中心修改手机号**，并在讨论区联系管理员，同时留意账号是否有异常操作记录。

::: danger 关于登录凭证的注意事项
登录凭证包括**密码、你的手机号与发出的短信、Passkey 设备、OTP 动态码**。其中任何一项泄露都可能危及账号：**不要把密码告诉别人，不要把手机借给他人操作登录，不要转发页面上的短信指令，不要透露 OTP 动态码**。请像对待银行卡密码一样对待这些凭证。
:::

::: warning 请勿使用一次性手机号
不要使用一次性手机号或他人代收的号码注册。此类账号功能受限，且一旦号码被回收，你将无法登录自己的账号，也没有办法找回。
:::

## 常见问题（FAQ）

这里汇总了新用户最常见的疑问。如果下面没有覆盖到你的问题，可以在讨论区发帖询问，也欢迎查阅其他文档。

### Q：用哪种登录方式最好？

- 日常使用建议**用户名 + 密码**，最通用，且不产生任何短信费用。
- 在常用设备上再启用 **Passkey**（指纹 / 面容免密），方便又安全。
- 对安全要求较高的用户，可在密码之外开启 **OTP** 二次验证（登录时还需输入动态码）。
- **手机号 + 短信**作为备用与找回途径，建议保持绑定，但日常登录不一定用它。

### Q：需要设置密码吗？

- **需要**。注册时请设置用户名与密码，密码用于日常登录。
- 如果你不想每次输密码，可以再启用 **Passkey**，用指纹 / 面容一键登录。

### Q：忘记密码怎么办？

- 在登录页选择"忘记密码"，通过绑定的**手机号发送短信**验证身份后即可重设密码。
- 因此注册后**务必绑定手机号**，它是找回密码的关键凭证。

### Q：Passkey 是什么？怎么用？

- Passkey（通行密钥）是**免密登录**方式：用设备自带的**指纹、面容或设备 PIN** 确认身份，无需输入密码。
- 在「账户中心 → 登录方式」中添加 Passkey 后，登录页选择 **Passkey 登录**即可。
- 建议在手机、笔记本等常用设备上各添加一个。

### Q：OTP 是什么？怎么用？

- OTP（一次性密码 / 动态验证码）是**二次验证**方式：它**不能单独登录**，而是配合密码（或 Passkey）使用——密码验证通过后，还需再输入一次身份验证器 App（如 Google Authenticator、Microsoft Authenticator）生成的 6 位动态码。
- 在「账户中心 → 登录方式」中开启 OTP，按页面提示用 App 扫描二维码完成绑定。
- 开启后，密码登录会变为两步：先输密码，再输动态码。即使密码泄露，没有动态码也无法登录。
- 请妥善保存绑定时的恢复码 / 备用码，以免更换手机后无法登录。

### Q：发送短信会收费吗？

- 会。这条短信由**你的手机按运营商正常短信资费发出**，会消耗你套餐内的短信条数或按条计费（通常不足一毛钱）。
- 请确认手机有足够的短信条数或余额，避免因欠费导致短信发不出去。
- 不过**日常登录无需发短信**：注册时发短信验证一次即可；之后用**用户名 + 密码**或 **Passkey** 登录，不会产生任何短信费用。短信登录只在你忘记密码、换设备等备用场景使用。

### Q：短信发出去了，但页面一直没有反应怎么办？

请按以下顺序排查：

1. **确认短信已发出**：到手机的"已发送"或短信记录中确认这条短信真的发成功了，收件人与内容与页面显示一致。
2. **检查收件号码**：确认短信的收件人号码与页面上显示的指定号码**完全一致**（不要多输、少输或输错数字）。
3. **检查短信内容**：确认短信内容与页面要求**完全一致**，包括大小写和特殊字符，不要多打空格。
4. **等待片刻**：平台接收与识别短信需要一点时间，通常几秒到十几秒，请保持页面打开耐心等待。
5. **按页面提示重试**：确认以上都没问题后，按页面提示重新发起验证。

::: warning
如果多次尝试仍然没有反应，可以改用**用户名 + 密码**登录，或在讨论区联系管理员反馈，说明你的手机运营商与号码归属地，以便排查。不要反复狂点发起按钮，这可能触发频率限制。
:::

### Q：提示"该手机号已注册"？

- 这说明该手机号**此前已经完成过验证**，说明你可能已经拥有账号。
- 直接按**登录**流程操作：用用户名 + 密码，或输入该手机号发送短信，即可登录原有账号。
- 如果确认这不是你的号码，请检查是否输错；若确认号码被他人注册，可在讨论区联系管理员核实处理。

### Q：修改手机号后，旧手机号还能用吗？

- 修改成功后，账号的绑定凭证就转移到了新手机号，**旧手机号不再关联**该账号（密码登录不受影响）。
- 请务必保存好新手机号，并牢记自己的账号数据（如昵称、UID），以备不时之需。

### Q：未成年人可以注册吗？

- 可以。流明是面向中小学的刷题学习平台，欢迎同学们注册使用。
- 注册时需要进行手机号验证，请使用自己或监护人名下的号码，并在家长知情、同意的前提下使用平台。
- 家长可以通过**家长监护**功能绑定学生账户，远程了解孩子的学习情况，详见[家长监护详解](/basic/guardian)。

### Q：一个手机号可以注册多个账号吗？

- **不可以**。一个手机号对应一个账号，验证后即与该账号绑定，无法用同一个号码重复注册新账号。
- 如果希望管理多个身份（例如学生账号之外再注册一个），需要使用不同的手机号分别注册，两个账号彼此独立。

### Q：换了新手机，会影响登录吗？

- 不会。你可以用**用户名 + 密码**登录；启用 Passkey 的设备换机后重新添加即可。
- 若旧手机号已停用，请先在原设备上**修改手机号**，或联系管理员协助处理，否则短信登录将无法完成验证。

### Q：使用非中国大陆手机号可以吗？

- 未认证中国大陆手机号的账户**功能将会受限**，可能导致无法完整使用平台各项服务。
- 建议使用真实有效的**中国大陆手机号**注册，以获得完整体验。

### Q：不小心退出了登录，数据会丢吗？

- 不会。你的练习记录、错题本、积分、收藏、团队数据等都保存在账号中，重新登录后一切照旧。
- 只要还记得密码或手机号，随时可以重新登录，数据永远不会因为登出而丢失。

### Q：可以在多个设备上同时登录吗？

- 可以。登录状态与设备无关，你可以在自己的电脑、手机等常用设备上使用同一个账号。
- 公用设备请务必登出，避免账号留在他人可用的环境中。

### Q：为什么我点击"登录"后页面跳转到另一个界面？

- 这是正常的。登录验证可能在独立的页面中完成，你看到的跳转正是验证界面。在这个页面完成密码 / 短信 / Passkey / OTP 验证后，会自动跳回流明。
- 只要验证通过，就完成了登录，无需担心"是不是被带到别的网站"。

### Q：忘记自己在哪个设备登录过，怎么办？

- 无需担心。直接打开流明，用任意一种方式重新登录即可。
- 如果怀疑某个公用设备上仍有登录残留，请尽快**修改密码**并开启 OTP，或联系管理员协助下线。

### Q：修改手机号会中断当前的登录状态吗？

- 不会。修改手机号后，当前设备上的登录状态依然有效，不需要立刻重新登录。
- 但**下一次**使用短信登录时，请务必使用新手机号完成验证。

### Q：手机停机或换卡了，还能登录吗？

- 可以。只要记得**用户名和密码**，仍可正常登录；Passkey 设备也不受影响。
- 若密码也遗忘且无法收到短信，请在讨论区联系管理员，说明情况并提供账号信息以便核实。

### Q：账号数据会因为我长时间不登录而删除吗？

- 不会。账号与数据长期保留，长时间不登录不影响任何记录。
- 只要还能通过任意一种方式登录，随时可以使用。

### Q：为什么提示"发起验证过于频繁"？

- 这是平台为防止滥用设置的**频率限制**。短时间内向同一个手机号发起过多验证，会触发该提示。
- 请等待几分钟后再尝试，不要在提示出现后继续狂点。
- 如果等待很久仍无法发起，可在讨论区联系管理员，说明你的手机号（仅需末四位）与具体时间。

### Q：可以用父母的手机号注册吗？

- 如果本人没有手机，可以使用监护人名下的手机号，但**务必征得家长同意**。
- 使用家长手机号注册后，后续短信登录与找回账号都需要经过该手机号，请与家长提前沟通好。

### Q：如何查看自己的 UID？

- UID 是平台为每个账号分配的唯一编号，可在**个人主页**或**账户中心**中查看。
- 联系管理员或参与绑定（如家长监护）时，可能需要用到 UID 来核对身份。

### Q：昵称可以修改吗？

- 可以在**账户设置**中修改昵称，具体操作见[账户与安全详解](/basic/account-safety)。
- 昵称是你在社区中的展示名，修改后其他人看到的就是新名字，历史记录不会追溯改名。

### Q：我可以注销账号吗？

- 目前平台不提供自助注销功能。如果你因特殊原因需要处理账号，请在讨论区联系管理员说明情况。
- 注销前请知悉：账号中的练习记录、积分、贡献等数据可能无法保留。

### Q：登录后为什么个人资料变了？

- 流明登录时会自动同步个人资料（用户名、邮箱、姓名、头像等）。
- 如果你在其他与流明互通的网页服务里修改了资料，登录流明时会同步更新；反之亦然。这是正常现象，无需手动处理。

### Q：被封禁后还能登录吗？

- 可以登录，但访问需要登录的功能时会收到**明确的封禁提示**（含原因与封禁状态），并引导进入申诉流程。
- 被封禁并不等于无法登录账号，具体机制见[账户与安全详解](/basic/account-safety)。

### Q：注册时提示手机号格式不正确？

- 请确认输入的是 **11 位**大陆手机号，且只包含数字。
- 检查是否混入了空格、短横线或其他符号；若手机号带国际区号，请按页面提示的格式填写。
