# 功能介绍

流明（https://liuming.franj2.top）是一个创建于 2026 年的刷题社区，覆盖小学至高中全学段、九大学科，提供在线练习、自动判题、组卷、比赛、团队协作、AI 批改等一站式学习服务。

本页面向新用户系统介绍流明的各项功能。使用前请先阅读[用户必读](/)。

## 输入与编辑器

流明所有文字输入框都使用统一编辑器，支持**可视化模式**与**代码模式**两种写法，并内置**可视化输入公式**（图形化拼搭 LaTeX、实时预览）：

- **可视化编辑器**：所见即所得的富文本编辑，用工具栏排版文字、插入公式，公式即时渲染，对不熟悉 Markdown 的用户非常友好。
- **代码模式**：传统 Markdown 源码编辑，带标题 / 加粗 / 列表 / 链接等快捷工具栏与数学符号面板。
- **可视化输入公式**：理科输入框（数学 / 物理 / 化学 / 生物）可点击符号与函数模板「拼」出公式（希腊字母、运算符号、分式、根号、上下标、积分求和、三角函数等），无需记忆 LaTeX。
- **模式可切换**：在「账户设置 → 编辑器模式」中二选一，全站输入框统一生效，且两种模式保存的都是 Markdown，切换不丢失内容。

详细教学见[输入与编辑器详解](/basic/editor)。

## 题库

题库是流明的核心，题目由社区用户贡献，经管理员审核后发布。

- **九大学科**：数学、语文、物理、化学、生物、英语、地理、历史、政治。数学、物理、化学、生物、地理、历史细分了子学科（如代数、几何、微积分、力学、电学、自然地理、中国古代史等）。
- **多种题型**：填空题、选择题（单选 / 多选 / 不定项）、等价表达式、判断题、证明题、应用题、简答题、作文题。部分科目支持听力题。
- **学段与难度**：题目按「小学低年级 / 小学高年级 / 初中 / 高中」划分学段；难度覆盖「送分 ~ 极难」的基础星级，以及「竞- ~ IMO+」的竞赛星级（仅理科保留竞赛星级）。
- **标签体系**：题目带有学科、学段、题型、知识点标签，支持多维筛选（关键词、科目、题型、学段、难度、标签）与按难度排序，方便精确查找。
- **题号（Code）**：每道题有唯一题号（如 `M0001`），用于组卷、引用与交流。
- **收藏**：可将常做的题目加入收藏，便于快速回顾。
- **贡献题目**：任何人都可以贡献题目，支持公式编辑、附件（如图片、听力音频）上传。贡献的题目经管理员审核后发布；题目的修改意见（新版本）也走审核流程，全程可追溯。

## 练习与判题

- **在线作答**：打开题目即可作答。填空、选择、等价表达式等客观题由系统自动判题，即时返回正确与否。
  - 填空题支持精确匹配、数值容差（±0.01 等）、百分比容差，以及常数计算求值（如 π、e）。
  - 选择题支持单选、多选、不定项三种模式。
  - 证明题、应用题、简答题、作文题等主观题可**自批**，或**邀请信任的人批改**。
- **多小题题目**：大题可拆分为多个小题，按小题分别作答、分别判分。
- **作答图片**：批改人与自批者可上传答案图片，便于展示手写作答过程。

## 学习数据与错题本

系统自动记录你的每一次练习，生成多维度的学习画像：

- **练习统计**：总提交数、正确率、累计用时、连续打卡天数、本周练习量。
- **错题本**：自动收集做错的题目，支持按学科筛选、检索，可随时移除已掌握的错题。
- **知识点雷达**：按学科（及子学科）展示正确率，直观呈现知识结构的强弱分布。
- **知识图谱**：将练习数据组织为知识图谱，标记「已掌握 / 发展中 / 薄弱」三级状态。
- **薄弱点分析与推荐**：系统识别正确率偏低的学科，并为你推荐针对性练习的题目。
- **AI 学习分析**：一键生成基于练习数据的 AI 分析报告。
- **练习热力图**：个人主页展示过去一年每天的练习量，记录你的坚持轨迹。
- **公开档案**：你的练习数据以公开档案的形式展示（提交记录、近期题目、热力图），可被他人访问。

## 计算专区

为小学、初中计算训练设计的专项练习，自动出题、自动批改：

- **七类计算**：口算、四则巧算、整式、小数计算、分数计算、一元一次方程、因式分解。
- **难度可选**：简单 / 中等 / 困难三档。
- **批量出题**：一次生成任意题量。
- **即时批改**：提交后逐题判分，返回正确率与分类统计。

## 组卷

输入题号即可生成一份完整的试卷 PDF：

- **按题号组卷**：每行一个题号（支持逗号、空格分隔），系统自动解析题目，可移除、清空、重新排序。
- **大题分组**：将小题拖入「大题」分组，可设置大题标题与分值。
- **试卷信息**：设置试卷标题、总分、完卷时间、考生须知、页脚页码；支持分值自动均分与一致性校验。
- **两种排版**：
  - **简易排版**：快速生成。
  - **复杂排版**：可精细配置密封线（范围、线型、圆圈、考生信息）、页眉、考生信息栏、选择题选项排版（列数、标签、间距）、填空样式（下划线 / 括号 / 圆圈等）、字体（西文 + 数学字体）、纸张（A4 / A3 / 自定义）、题册模式（封面、预留作答区）、教师版（在填空/括号内显示答案、题解随附）等。
- **导出选项**：支持附题解（教师版）、防复制；PDF 由后端 LaTeX 编译生成，公式排版专业。
- **在线保存**：组卷稿件可在线保存、读取、继续编辑，随时下载 PDF。
- **从题单 / 比赛继承**：可从题单或比赛一键带入题目列表进行组卷。

## 整卷库

整卷库是**整份试卷文件**的共享社区，与「组卷」生成功能互补：

- **上传整卷**：上传完整试卷文件（PDF / Word / PPT / TXT，最大 50MB），填写标题、科目、学段，可选关联公开题单；提交后由管理员审核。
- **浏览与下载**：浏览社区用户上传的整卷（按科目、学段、状态筛选），登录后即可下载。
- **举报违规**：发现违规 / 侵权内容可举报，进入工单系统由管理员复核。

详细说明见[整卷库详解](/basic/paper-uploads)。

## 比赛

流明支持在线竞赛的组织与参与：

- **创建比赛**：自定义标题、描述、可见性（公开 / 私有 / 团队私有）、批改方式（创建者批改 / 指定批改人 / 自批）、科目与题目。
- **命题协作**：创建者可邀请命题人共同维护题目。
- **参赛管理**：公开比赛可自由报名；私有比赛通过邀请码或指定参赛者加入。比赛可设定开始 / 结束时间，随时开始或结束。
- **在线作答与判题**：比赛中逐题作答；客观题自动判题，主观题由批改人（或参赛者自批）判分。
- **排行榜**：按答题正确数实时排名。
- **导出试卷**：比赛一键生成 PDF 卷子（附带题解仅管理员可用）。
- **重现赛**：一键克隆比赛题目与配置、重新开赛，适合反复练习或举办系列赛。
- **公开审核**：公开比赛需要管理员审核后发布，保障内容质量。

## 团队

团队是面向班级、社团、兴趣小组的协作空间：

- **团队管理**：创建团队（生成团队邀请码）、邀请成员、设置管理员、成员加入 / 退出、移出成员。
- **团队私题**：团队内部题库，可上传仅限团队使用的私有题目。
- **作业系统**：
  - 布置作业：从题库、团队私题、题单或比赛继承题目，设置截止时间与指定参与成员。
  - 作业作答：成员在线作答，客观题自动判题，主观题可手动批改（AC / WA / PENDING）。
  - 作业管理：改题、增删、排序、全量替换作业题目（仅影响本次作业，不改题库）。
  - 排行榜与统计：作业完成率、正确率排行；导出 CSV 成绩单。
- **团队比赛**：团队内可举办私有比赛（通过邀请码加入），统计与排名独立。
- **团队数据看板**：成员贡献（出题数、作业 / 比赛提交与正确率）一目了然。

## 题单

题单是按主题整理的题目合集，方便系统化学习：

- **创建题单**：自定义标题、简介、标签与学科，按需添加题目、调整顺序。
- **公开与私有**：公开题单经管理员审核后对全站可见；私有题单仅自己（或指定团队）可见。
- **应用场景**：老师整理专题练习、同学分享备考资料、比赛题目合集等。

## 批改中心

集中管理所有需要人工批改的作答：

- **邀请批改**：主观题作答可邀请任意用户批改，被邀请人看到题目、标准答案与题解后进行判分。
- **自批**：自己对照题解判分。
- **AI 批改**：对特定科目，可调用 AI 自动批改并返回详细反馈（判分 + 评语）。
- **额度管理**：组卷与 AI 批改按套餐享有每周额度，额外额度由管理员授予，用量在个人中心实时可见。

## 家长监护

家长可以绑定学生账户，远程了解孩子的学习情况（需学生同意）：

- **绑定关系**：家长通过学生 UID 发起绑定申请，学生同意后建立监护关系，可随时解除。
- **学习数据查看**：绑定后家长可查看学生的练习统计、提交记录、错题本、知识图谱、知识点雷达、薄弱点分析、收藏与近期练习、练习热力图，并可生成 AI 学习分析报告。

## 讨论与专栏

- **讨论区**：与社区用户交流学习心得、题目解法。
- **专栏**：发布文章，分享经验与知识。

## 成就

练习与参与社区活动会解锁成就，记录你的学习里程碑。

## 积分与权益

社区贡献会转化为积分，并能兑换成实用权益：

- **获得积分**：你的题目 / 题单贡献被审核通过时发放积分（分值由管理员审核时决定）。
- **积分流水**：每笔积分的获得与消耗都有完整流水记录。
- **权益兑换**：消耗 15 积分可兑换 **30 天三倍额度**（组卷与 AI 批改周额度 ×3）。

详见[积分与权益详解](/basic/rewards)。

## 账户与安全

- **统一登录**：支持**用户名 + 密码、手机号 + 短信、Passkey（指纹 / 面容免密）、OTP 动态验证码**等多种登录方式，安全登录、自动续期，可自由组合与切换（详见[注册与登录](/basic/account)）。
- **封禁与申诉**：违反[社区规则](/policies/rule)会依据违规周期与再犯机制受到处罚（警告 / 禁言 / 封禁等）。被封禁用户可通过封禁工单提交申诉，补充材料，由管理员复核。
- **举报与工单**：可举报违规题目 / 题单（支持附加图片）；工单系统全程记录处理事件，处理结果可申诉。
- **账号数据**：个人主页展示档案、练习热力图、提交记录、近期练习、收藏与错题，账号资料登录后自动同步。
