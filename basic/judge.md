# 练习与自动判题详解

本页详细介绍流明如何作答、判题，以及答案解锁机制，帮助你理解不同题型的行为差异。

## 一、在线作答

登录后进入任意题目即可作答。作答体验由**题型**决定：

- **填空题 / 选择题 / 等价表达式 / 判断题**：直接在答题区填写或选择。理科的等价表达式与填空支持通过**可视化输入公式**输入数学公式（见[输入与编辑器详解](/basic/editor)）。
- **选择题**：按题目配置为单选 / 多选 / 不定项。
- **证明题 / 应用题 / 简答题 / 作文题**：本题无标准答案，作答后进入**待批改**状态，需[批改](/basic/grading)或自批。
- **听力题**：可播放听力音频作答，听力材料可辅助判题。

### 多小题题目

大题可拆分为若干小题（最多 20 个）。多小题各自独立作答、独立判分：

- 逐小题判定，**部分小题答对也算对**（只要各小题答案匹配）。
- **未作答的小题跳过判定**，不影响已答小题的结果。
- 只要存在「待批改」的小题（如证明题小题），整个提交就保持待批改，不会因部分自动正确而跳过人工批改。

## 二、自动判题机制

系统会**自动比对**你的答案与标准答案是否「等价」——即内容相同但写法不同也能判为正确。判题覆盖填空题、选择题、等价表达式、判断题；证明、应用、简答、作文无标准答案，返回「待批改」。

::: note 语言类题目不自动判分
语文 / 英语的填空、简答、作文题，即使配置了答案也**不会自动判分**，无论对错都交由人工批改或自批（避免语言类答案被僵化地套用唯一标准）。
:::

### 答案的标准化

提交与标准答案都会先做「规范化」后再比较，因此不同的常见写法都能被正确识别为同一答案，例如：

- 去除所有多余空白；全角符号自动转半角（`，`→`,`、`（）`→`()`）。
- 统一常见数学命令写法，如 `\cdot`、`\times` 视为乘、`\div` 视为除、`\frac{a}{b}` 视为 `(a)/(b)` 等。
- 整体转为小写。

所以 `π/2` 与 `\frac{\pi}{2}`、`1/2` 与 `0.5` 之类写法都能判为同一答案。

### 容差与数值比较

填空题 / 等价表达式支持数字按精度的比较：

- **绝对容差**：如 `0.01`，接受与标准值相差 ±0.01 以内的答案。
- **百分比容差**：如 5%，接受与标准值相对误差在 ±5% 以内的答案。
- 无容差时按极小的默认精度比较数值。

此外，规范化后的表达式支持**安全数学求值**：将 `π`、`e` 等常数自动替换为精确值，再计算常见数学函数（绝对值、开方、三角函数、指数对数、幂、舍入、取整、最值等），因此 `π`、`e`、`sin(...)` 等都能正确比较。

::: warning 求值安全性
为了让「不同写法」都能判对，系统会对含数学函数的表达式做受限求值；但该求值仅允许白名单函数并做了严格安全防护，**不会执行任意代码**，可放心使用。
:::

### 条件判定（AND / OR）

标准答案支持**多层条件结构**，构成灵活的判定规则：

- **OR 组**：任一规则匹配即判对（例如既接受 `pi/2` 又接受数值 `1.57`）。
- **AND 组**：所有规则都须匹配才判对。
- 条件可**嵌套**，构成树状判定逻辑（适合「只有一道题有多种等价写法」的题目）。

### 判断题令牌

判断题对「是 / 否」类答案做令牌匹配，因此多种写法都能判对：

- 视为**真**：`true / t / 1 / √ / 是 / 对 / yes`。
- 视为**假**：`false / f / 0 / × / 否 / 错 / no / x`。

### 选择题判定

- **单选**：你的选择与正确选项完全一致即对。
- **多选 / 不定项**：将你勾选的**选项集合**与正确**选项集合**做**集合相等**比较——必须全选对才得分，与勾选顺序无关。

## 三、答案解锁机制

为了保护参考答案、鼓励独立思考，题目答案与题解**不直接暴露**，而是通过练习解锁：

- 解锁条件：**答对该题**，或**累计提交达到一定次数**。
- 未解锁前，不会返回标准答案与题解（多小题同样隐藏各小题答案）；选择题仍保留选项标记，供作答使用。
- 一旦解锁，即可查看本题标准答案与详细题解。

::: tip 想早点看答案？
认真作答一次就解锁（答对即显示）！如果一直没答对，多提交几次也会自动解锁到参考答案与解析。
:::

解锁后，答案区下方还可能提供**AI 生成的题解**（部分题目，详见[题库详解 · AI 题解](/basic/bank#九、ai-题解)）。

## 四、正确率与动态难度联动

每次提交都会更新该题的提交数与正确数，并据此**动态重新计算题目的难度评分**（详见[题库详解·动态难度评分](/basic/bank#动态难度评分rating)）：

- 正确 → 提交数与正确数各自 +1。
- 题目的累计提交达到阈值后，按正确率与期望正确率（50%）动态调整难度数值。

## 五、自我批改（自批）

对**待批改**的作答（证明题、应用题、简答题、作文，以及语文 / 英语的填空、简答、作文），你可以：

- **自批**：对照题解自我判定对 / 错。客观小算题的也可逐小题自批。
- **上传作答图片**：自批时如需展示手写作答全过程，可上传图片，方便记录与批改。

「待批改」状态会贯穿到你的练习记录、错题本与批改中心，直到完成判分。

::: tip 时间有限怎么办？
不想等人批改时，可优先**自批**或使用**AI 批改**（见[批改中心](/basic/grading)），即批改又即时。
:::
