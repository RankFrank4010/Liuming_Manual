# 批改中心详解

主观题（证明、应用、简答、作文等）以及语文 / 英语的部分填空、简答、作文没有自动标准答案，需要**人工判分**。批改中心集中管理这些待批改的作答，提供三种批改方式：邀请批改、自我批改、AI 批改。

## 一、哪些作答需要批改

由[自动判题](/basic/judge)判定为「待批改」的提交：

- **证明题 / 应用题 / 简答题 / 作文题**（无标准答案）。
- **语文 / 英语**的填空、简答、作文（即使有答案也不自动判分）。
- 多小题中只要存在待批改的小题，整个提交保持待批改。

## 二、自我批改（自批）

最简单的方式：对照**题解**自己判断正确与否。

- 在提交详情中查看题解后，标记该提交对 / 错。
- 多小题可**逐小题自批**。
- 自批时可**上传作答图片**，方便记录手写作答或作为留档。

## 二、邀请批改

当你希望由更权威的人判分时，可**邀请他人批改**你的作答：

1. **发起邀请**：在待批改提交上「邀请批改」，指定被邀请人并附一段说明文字。
2. **对方处理**：被邀请人在「批改中心」看到待批改邀请（含题目、标准答案、题解、你的作答），可当场**判分**（正确 / 错误），完成后邀请状态变为已批改。
3. **多次批改 / 移除**：可更换批改人、撤回邀请。

邀请的完整流转为：**待对方处理 → 接受 / 拒绝 → 已交由对方批改（通常一并判分）**。邀请人与被邀请人分别可在「已发送邀请」与「待批改邀请」列表查看进度。

::: note 批改人会看到答案
被邀请的批改人会看到题目的**完整题干、标准答案与题解**，以便做出准确的判分。
:::

## 三、AI 批改

对符合条件的待批改提交，可一键调用 **AI 自动批改**：

- 系统将**题目、参考答案与你的作答**组装成提示词，调用 AI 模型输出判分结果与文字评语。
- 返回**判分结果（正确 / 错误）**与**详细文字反馈**，供你理解错因。
- 若 AI 输出无法解析，系统会自动重试；最终失败会**退回已消耗的额度**。

::: tip 说明
AI 批改的模型、温度、限额等由管理端统一配置（见[管理后台](/basic/account-safety#管理后台)）。AI 批改用于辅助，最终判断请以实际反馈并结合自己的理解为准。
:::

### 常见情况

调用 AI 批改可能出现：**额度用尽**、**已被批改**（无法重复）、**批改失败**、**服务未开启**、**提交不存在或不可批改**等提示，按提示处理即可。

## 二、额度管理

**组卷（PDF 导出）**与 **AI 批改**都受**套餐额度**约束：

- **套餐**：为用户分配**每周组卷额度**与**每周 AI 批改额度**。无套餐时额度为 0（或仅有基础配额）。
- **额外额度**：管理员可针对用户授予额外的组卷 / AI 批改次数，与套餐额度叠加。
- **用量**：本周已使用的组卷 / AI 批改次数。
- **可用额度**：`套餐额度 + 额外额度 - 本周已用`，实时在「个人中心」可见。
- 若 AI 批改最终失败，会**退回**本次已消耗的额度。

::: info 哪些会扣额度？
仅**组卷导出**与 **AI 批改**这两个「算力密集型」能力按额度计费；邀请批改、自批**不消耗**任何套餐额度。
:::

::: tip 额度为什么有限制？
额度是为了防止服务器超负荷运行而设：组卷（PDF 由后端 LaTeX 编译）与 AI 批改（调用大模型）都消耗大量算力，不设限会让少数用户的过度使用拖垮服务器、影响所有用户。**本站不提供付费套餐**，额度无法通过付费购买或充值获得，由平台统一免费分配；额外的额度只能通过[积分兑换三倍额度](/basic/rewards#三、兑换权益)或管理员授予获得。
:::
