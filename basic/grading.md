# 批改中心详解

主观题（简答、作文等）以及语文 / 英语的部分填空、简答、作文没有自动标准答案，需要**人工判分**。批改中心集中管理这些待批改的作答，提供多种批改方式：邀请批改、自我批改、AI 批改，以及提交后自动触发的 AI 辅助批改。

## 一、哪些作答需要批改

由[自动判题](/basic/judge)判定为「待批改」的提交：

- **简答题 / 作文题**等无标准答案题型（原「证明题 / 应用题」已并入简答）。
- **语文 / 英语**的填空、简答、作文（即使有答案也不自动判分）。
- **口语题**：AI 自动评分（0~10 分，0.5 步进），读取学生录音按参考文本打分。
- 多小题中只要存在待批改的小题，整个提交保持待批改。

## 二、自我批改（自批）

最简单的方式：对照**题解**自己判断正确与否。

- 在提交详情中查看题解后，标记该提交对 / 错。
- 多小题可**逐小题自批**。
- 自批时可**上传作答图片**，方便记录手写作答或作为留档。

## 三、邀请批改

当你希望由更权威的人判分时，可**邀请他人批改**你的作答：

1. **发起邀请**：在待批改提交上「邀请批改」，指定被邀请人并附一段说明文字。
2. **对方处理**：被邀请人在「批改中心」看到待批改邀请（含题目、标准答案、题解、你的作答），可当场**判分**（正确 / 错误），完成后邀请状态变为已批改。
3. **多次批改 / 移除**：可更换批改人、撤回邀请。

邀请的完整流转为：**待对方处理 → 接受 / 拒绝 → 已交由对方批改（通常一并判分）**。邀请人与被邀请人分别可在「已发送邀请」与「待批改邀请」列表查看进度。

::: note 批改人会看到答案
被邀请的批改人会看到题目的**完整题干、标准答案与题解**，以便做出准确的判分。
:::

## 四、AI 批改

对符合条件的待批改提交，可一键调用 **AI 自动批改**：

- 系统将**题目、参考答案与你的作答**组装成提示词，调用 AI 模型输出判分结果与文字评语。
- 返回**判分结果（正确 / 错误）**与**详细文字反馈**，供你理解错因。
- 若 AI 输出无法解析，系统会自动重试；最终失败会**退回已消耗的额度**。

### 口语题 AI 评分

口语题采用**分数制批改**（0~10 分，0.5 步进），AI 自动评分流程：

- 系统读取学生录音，按**参考文本**进行语音识别与评分。
- 评分维度包括发音准确度、流利度、内容完整性等。
- 评分结果为 0~10 分，步进 0.5 分，支持半分制精度。
- 口语题在题目作答、竞赛、团队作业中均支持录音作答与分数制批改。

### AI 辅助批改（无标准答案题）

从 v1.0 起，**无标准答案**的题目（简答 / 作文等自批、邀请批改类）在你**提交后会自动触发 AI 辅助批改**，无需手动操作，也**不消耗 AI 额度**。

提交后会看到以下提示之一，按提示处理即可：

| 你看到的提示 | 含义与你要做的事 |
| --- | --- |
| 「AI 辅助批改中，请稍候…（不消耗 AI 额度）」 | 正在异步批改，稍候即可，无需操作。 |
| 「AI 已完成批改，并根据批改结果更新了本题标准答案」 | 已判好，查看结果即可；本题标准答案已按批改结果更新。 |
| 「AI 已批改部分小题，请对剩余小题继续自评」 | 只判了部分小题，**剩余小题请自己自评**。 |
| 「该题无法自动判题，已转交管理员审核；你也可以先自评」 | 已转交管理员；你也可先自评。 |
| 「AI 无法批改此题（如题目含图片而 AI 不支持），需要人工批改，请自评」 | 请**自评**或请人批改。 |
| 「AI 辅助批改失败，请自评」 | 请**自评**。 |

- 该功能由管理端「AI 批改」页的**总开关**控制；未开启时提交后不会触发，按普通待批改处理（自批 / 邀请批改）。

::: tip 说明
AI 批改的模型、温度、限额等由管理端统一配置（见[管理后台](/basic/account-safety#六、管理后台)）。AI 批改用于辅助，最终判断请以实际反馈并结合自己的理解为准。
:::

### 常见情况

调用 AI 批改可能出现：**额度用尽**、**已被批改**（无法重复）、**批改失败**、**服务未开启**、**提交不存在或不可批改**等提示，按提示处理即可。

## 五、额度管理

**组卷（PDF 导出）**与 **AI 批改**都受**套餐额度**约束：

- **套餐**：为用户分配**每周组卷额度**与**每周 AI 批改额度**。无套餐时额度为 0（或仅有基础配额）。
- **额外额度**：管理员可针对用户授予额外的组卷 / AI 批改次数，与套餐额度叠加。
- **用量**：本周已使用的组卷 / AI 批改次数。
- **可用额度**：`套餐额度 + 额外额度 - 本周已用`，实时在「个人中心」可见。
- 若 AI 批改最终失败，会**退回**本次已消耗的额度。

::: info 哪些会扣额度？
仅**组卷导出**与 **AI 批改**这两个「算力密集型」能力按额度计费；邀请批改、自批**不消耗**任何套餐额度。
:::

::: tip 额度为什么有限制？
额度是为了防止服务器超负荷运行而设：组卷（PDF 由后端 LaTeX 编译）与 AI 批改（调用大模型）都消耗大量算力，不设限会让少数用户的过度使用拖垮服务器、影响所有用户。**本站不提供付费套餐**，额度无法通过付费购买或充值获得，由平台统一免费分配；额外的额度只能通过[积分兑换三倍额度](/basic/rewards#三、兑换权益)或管理员授予获得。
:::

## 六、标记优秀作业（团队管理员）

团队管理员在团队作业的「批改」标签页，可对任意已批改（AC / WA / SCORED）的提交**标记为优秀作业**：

- 标记后该提交自动出现在团队主页「**优秀作业**」展示区，团队全员可见。
- 系统自动入账「**作业获评优秀**」事件（默认 +10 分，可在「排名 → 规则」中调整），并写入积分账本。
- **取消标记**会**冲销**对应账本记录（分值取反），不会重复奖励。
- 详细规则与展示位置见[团队详解：优秀作业](/basic/team#九、优秀作业)。
