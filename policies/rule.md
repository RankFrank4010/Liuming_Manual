# 社区规则及处罚
为保证社区的正常运行，特制本规则。本规则适用于本站一切功能。
本规则会根据具体情况进行更改。

## 第一章 总则

### 第一条 目的
本规则的制定旨在维护流明社区的正常运行秩序，保障题库、练习、比赛等各项功能的公平与稳定，为每一位用户提供安全、友善、诚信的学习环境。用户使用本站即视为同意遵守本规则，违规行为将依据本规则受到相应处罚。

### 第二条 适用范围
本规则适用于本站一切功能，包括但不限于：题库与练习、判题与评测、组卷、整卷库、比赛、团队、题单、批改中心、讨论区、专栏、私信、工单系统、积分与权益等。凡在站内实施的行为，无论发生在哪个功能区域，均受本规则约束。

### 第三条 基本原则
1. **遵纪守法**：不得违反中华人民共和国法律及用户所在地法律，不得发表违法违规内容。
2. **尊重友善**：尊重他人，友善交流，不发布侮辱、歧视、人身攻击等内容，不泄露他人隐私。
3. **学术诚信**：如实作答，诚信参赛，不抄袭、不作弊，不破坏评测与比赛秩序。
4. 用户在遵守本规则的同时，还需遵守《用户服务条款》及各项专项规范；专项规范有规定的，优先适用专项规范。

## 第二章 处罚

### 第四条 处罚类型
违反规则的用户将根据具体类型、程度受到以下处罚：
1. 警告：我们将通过各种渠道（如邮箱、站内弹窗等）警告用户。
2. 禁言：禁止在本站任何区域发言。
3. 封禁论坛：在有限期内或无限期，剥夺访问论坛的权限或使用论坛具体功能的权限。
4. 封禁账户：有限期或无限期地禁止登录本站；封禁可附带限制项（如限制练习、组卷、比赛等）。
5. 其他必要措施。

::: tip
每次封禁都以**工单**形式完整记录，包含发起与处理经过、具体限制项与时长、申诉与复核结果，全程可追溯。详见[账户与安全详解](/basic/account-safety)。
:::

### 第五条 连坐制
1. 如果用户使用自己多个账户之一违规，或被罚后注册、使用其他账户绕过处罚，所有关联账户将追加同等或更重处罚。
2. 同一来源内若有频繁违规，平台将对该来源施加访问限制；如果您确定该限制是由于 NAT 等不可控原因造成，可联系我方说明情况申请调整。
3. 团队发生严重违规时，该团队将会被封禁，创始人与管理员将会受到连坐处罚。团内用户违规的也将受到相应处罚。

### 第六条 处罚的执行
1. **举报渠道**：发现违规内容或违规行为，可通过以下渠道举报：
   - 讨论区：对违规的帖子、回复使用举报功能。
   - 工单系统：对违规的题目、题单、整卷等提交举报，附上理由（可附加图片），系统会同步创建工单与处理事件。
2. **管理员处置**：经核实属实的违规内容，管理员可视情况**删除、屏蔽、下架或驳回**相关内容，并依据本规则对违规者作出相应处罚。
3. **公示说明**：每一次封禁都以工单形式记录，公开可查询当前与历史的违规周期；被封禁用户的公开档案会明确显示封禁状态，访问受限功能时也会收到明确的封禁提示。

## 第三章 违规行为与处罚细则

### 第七条 违规周期

::: danger 不要滥用规则
违规周期、再犯判定的设计目的是为了防止用户长期因过往偶尔的违规记录而长期失信。如果确凿认为你在把规则当任务列表，我们将会依情节赠送十年违规周期、十年惯犯认定大礼包。
:::

自用户第一次犯规开始的365天为一违规周期。违规周期内再次违规，该违规周期的结束时间将延长在最后一次违规的365天后。违规周期内该用户主页上会显示该周期内的所有违规。
**所谓"再犯"就是在违规周期内再次违反该违规周期违反过的相同规则。**
违规周期结束后，违规周期的相关影响将会停止（包括但不限于违规公示、再犯判定等）但违规仍然会内部留档。
<br/>

**如果被罚禁言、封号等，违规周期会有惩罚性同等加时。**

在有必要的情况下，经流程，可以单独处罚违规周期延时特定时长、惯犯最坏认定（即周期内始终认为你是惯犯）。

### 第八条 一般扰乱秩序

用户在公开区域（如论坛）作以下行为将会受到**警告**、**禁言**。严重者、惯犯将加重处罚或受**封禁账户**：
1. 发布令人反感、哗众取宠的内容或恶作剧：第一次违规，警告。再犯，禁言1周。惯犯，禁言一个月并逐次加一个月。
2. 大规模发送无意义内容：第一次违规，警告。再犯，禁言半年。惯犯，封禁半年并逐次加半年。
3. 发送不友善内容（辱骂、歧视、人身攻击等）：第一次违规，警告。再犯，禁言2周。惯犯，禁言半年并逐次加一年。
4. 泄露他人隐私：首犯，禁言2周。惯犯，封禁账号半年并逐次加两个月。
5. 在不正确的地方发送内容：首犯，警告；再犯，禁言一周并逐次加一周。
6. 未经授权发布广告：首犯，禁言半年；惯犯，永久禁言。

### 第九条 严重扰乱秩序
有以下行为将**封禁账号**：
1. 发表违反中华人民共和国相关法律的内容、敏感话题（政治相关内容、自残、自杀、黄赌毒等）、严重违反社会公德的言论：永久封禁。
2. 故意浪费本站资源（比如爬虫、逆向、网络攻击、浪费算力资源（卡测评等））：永久封禁。
3. 浪费本站行政资源：如贡献无意义的题目：禁止相关权限。
4. 多次创建小号并依此扰乱秩序：首犯，封禁主号一年并永久封禁所有小号；再犯，永久封禁所有账户。
5. 其他对本站运行产生不良影响的行为：特殊裁定。

### 第十条 一般违反学术诚信

在练习、评测、作业、比赛等场景中违反学术诚信要求的行为，将根据情节受到**警告**、**禁言**，情节严重的将**封禁账户**或**撤销相关贡献**。包括但不限于：
1. 在评测或作业中抄袭他人代码或答案，或直接提交 AI 生成的代码、答案并伪称为自己作答（AI 的使用边界见[AI 使用规范](/academic/ai)）：首犯，警告并撤销该次成绩；再犯，禁言两周并撤销相关成绩；惯犯，封禁账户一个月起，逐次加重。
2. 违反比赛参赛规则（如一人多账号参赛、代打、赛时交流答案等）：按第十二条处理，并取消相关比赛成绩。
3. 贡献抄袭他人题目、题单，或整卷、题解、专栏文章抄袭他人成果：首犯，撤销相关贡献并警告；再犯，禁言一个月并禁止相关权限；惯犯，封禁账户并永久撤销相关贡献。

### 第十一条 严重破坏学术与评测秩序
有以下行为将**封禁账户**，情节严重的**永久封禁**：
1. 大量提交无意义答案（如随机、重复、空白或明显与题目无关的答案）干扰评测：首犯，警告并撤销相关成绩；再犯，封禁账户一个月；惯犯，封禁账户一年起，逐次加重。
2. 恶意刷评测（利用脚本或漏洞批量提交、反复提交以操纵成绩或排行榜等）：封禁账户，时长视情节而定。
3. 创建诱导他人作弊的题目、题单或整卷（如以作弊为目的设计内容）：永久撤销相关贡献并封禁账户。
4. 屡次抄袭不改：在违规周期内因学术诚信问题被多次处罚仍继续抄袭的，视为惯犯，按第十条顶格处罚并加重处理。

### 第十二条 比赛相关违规
参赛者在比赛中须遵守[比赛规范](/academic/competition)。以下行为将受到**取消成绩**、**禁言**或**封禁账户**等处罚，情节严重的**永久封禁**：
1. 一人多账号参赛：首犯，取消相关成绩并警告；再犯，封禁账户一个月；惯犯，封禁账户一年并永久封禁小号。
2. 代打（代替他人参赛或由他人代替自己参赛）：首犯，取消成绩并禁言两周；再犯，封禁账户半年。
3. 赛时交流答案（在比赛进行期间向他人索取或泄露答案）：首犯，取消成绩并警告；再犯，禁言两周；惯犯，封禁账户一个月起，逐次加重。
4. 使用违规辅助（如攻击系统、利用漏洞作弊等）：永久封禁账户。

## 第四章 举报与申诉

### 第十三条 举报
1. **举报渠道**：可在流明讨论区举报违规帖子，或在工单系统中对违规的题目、题单、整卷提交举报。
2. **材料要求**：举报时请说明违规理由，附上必要的截图、链接等材料；涉及题目、题单的举报支持附加图片，便于管理员核实。
3. **处理流程**：举报会同步创建工单，每次状态变更都会生成事件（操作人、原因、时间），形成可追溯的处理时间线。
4. **恶意举报**：无依据、滥用举报功能干扰他人或浪费行政资源的，按第八条「一般扰乱秩序」处理。

### 第十四条 申诉
1. **封禁申诉**：被封禁用户可对封禁工单提交申诉并附理由。管理员可作出批准（解封）、驳回（维持）、调整处罚（改判）或要求补充材料。被要求补充材料的，应按时补齐，否则申诉可能不会被继续处理。
2. **内容申诉**：对被拒绝的题目、题单贡献，可提起申诉请求复核，管理员处理后给出最终结果。
3. **申诉时限**：封禁申诉与内容申诉均应在收到结果后及时提出，具体时限以工单提示为准；无正当理由超期提出的，可能不予受理。

### 第十五条 自首从轻
在违规行为尚未被处理前主动向管理员说明情况、承认错误并配合处理的，管理组可视情节**从轻或减轻处罚**。自首不影响对已造成影响的纠正。

## 第五章 处罚解除

### 第十六条 处罚解除
1. **期满自动解除**：有限期的处罚（禁言、封禁论坛、封禁账户等）在期满后自动解除，工单状态更新为「已结束」。
2. **申请解除**：对处罚有异议或认为处罚已无必要的，可通过封禁工单提交申诉，由管理员评估后决定是否解除、调整或维持。
3. **评估机制**：管理组会根据违规性质、周期内的累犯情况、改正表现等因素综合评估；永久处罚不适用期满自动解除，仅可通过申诉由管理员裁量。

## 第六章 附则

### 第十七条 数量定义
本规则所称数量定义如下：

| 表述 | 含义 |
| --- | --- |
| 以上 / 以下 | 含本数 |
| 多次 | 两次及以上 |
| 大量 | 多次以上，即三次及以上 |
| 首犯 / 再犯 / 惯犯 | 按第七条「违规周期」的认定规则 |

### 第十八条 规则效力
1. 用户需同时遵守《用户服务条款》、本规则及各项专项规范（如[学术规范](/academic/)、比赛规范）。
2. 专项规范与本规则不一致的，优先适用专项规范；专项规范未尽事宜，适用本规则。

### 第十九条 特别裁量权
本规则未尽事宜，或个案情节复杂、不宜直接适用上述条款的，由管理组依职权裁定。管理组对特定情节可采取本规则未列明的必要措施（见第四条「其他必要措施」）。

### 第二十条 生效与修订
1. 本规则自发布之日起生效。
2. 本规则会根据平台发展情况适时更新，修订后的版本将在本页公布；修订不溯及既往，但违规周期内的持续违规行为除外。
