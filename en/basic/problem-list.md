# Problem List Details

A problem list is a collection of problems organized by topic, making it easy to practice systematically, review a specific topic, or share exam-preparation materials.

## Creating a Problem List

On the "Problem Lists" page, click create and fill in:

- **Title** and **description**: describe the problem list's topic and learning path.
- **Subject / tags**: mark the subjects and knowledge-point tags involved so others can find it.
- **Visibility**:
  - **Public**: visible to the whole site. **Public problem lists require admin review** before being published.
  - **Private**: visible only to you, or visible within a team after linking to that team.

::: note Think it through before going public
A public problem list only becomes visible site-wide after admin review; if you only want to share it with a small circle, you can keep it private and link it to your team instead.
:::

## Managing Problems in a List

- **Add problems**: add problems to the list from the problem bank by problem number or by searching.
- **Remove problems**: delete a problem from the list.
- **Reorder**: drag to adjust the problem order and build a gradual learning path.
- **Notes**: add a note to a specific problem in the list.

## Browsing and Using

- Public problem lists are visible in the "Problem Lists" index and can be searched by keyword, subject, type, and tag.
- Inside a list, you can practice all its problems in order or on demand; objective problems are auto-judged as usual and subjective problems are graded as usual.
- "My Problem Lists" centrally manages the lists you created (including rejected / pending ones) and lets you edit or delete them.

## Review

- After submission, a public problem list enters **pending review**; it becomes site-wide visible once an admin approves. Rejections come with a reason.
- Additions and edits to problem lists are also recorded through the ticket system.

## Use Cases

- Teachers put together "unit topic" practice sets.
- Students share "exam sprint" material collections.
- As a **problem source** for competitions / homework / paper generation: when adding problems to a competition, assigning team homework, or generating a paper, you can choose to **inherit problems** from a problem list (see [Competition Details](/en/basic/competition), [Team Details](/en/basic/team), and [Paper Generation Details](/en/basic/paper)).

## Related

- The problems in a list follow the same system as the [problem bank](/en/basic/bank) and [problem numbers](/en/basic/bank#question-codes), and all of them can be used for paper generation and competitions.
