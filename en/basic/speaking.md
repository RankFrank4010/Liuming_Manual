# Speaking Questions

Speaking questions are designed for English oral practice and competitions on the LiuMing platform, supporting recording submissions and AI automatic scoring.

## 1. Features

- **Recording Submission**: Students record audio through the browser, and the system automatically saves the audio file.
- **AI Automatic Scoring**: The system calls a multimodal AI model to perform speech recognition and scoring based on the reference text.
- **Score-based Grading**: Scoring range 0-10 points, with 0.5 point increments, supporting half-point precision.
- **Multi-scenario Support**: Speaking questions can be used in problem practice, competitions, and team assignments.

## 2. Question Structure

A complete speaking question includes the following elements:

### 2.1 Question Stem

The question stem describes the requirements, for example:
- "Please read the following sentences aloud"
- "Please describe the picture"
- "Please answer the following questions"

### 2.2 Reference Text

**Reference text is the core of speaking questions**, used to compare with student recordings during AI scoring.

Reference text requirements:
- **Clear and Complete**: Should be the complete content that students need to read aloud or repeat.
- **Unambiguous**: Avoid vague expressions to ensure accurate AI evaluation.
- **Appropriate Length**: Recommended 1-3 sentences; too long will affect scoring accuracy.

### 2.3 Attachments (Optional)

Images, audio, and other auxiliary materials can be uploaded to help students understand the question requirements.

## 3. Answering Process

### 3.1 Student Submission

1. Enter the speaking question page.
2. Read the question stem and reference text.
3. Click the "Record" button to start recording.
4. Read aloud or repeat the reference text content.
5. Click the "Stop" button to end recording.
6. You can listen to the recording, and submit when confirmed.

### 3.2 AI Scoring

After submission, the system automatically calls the AI model for scoring:

1. **Speech Recognition**: Convert student recording to text.
2. **Content Comparison**: Compare recognized text with reference text.
3. **Multi-dimensional Scoring**: Score from pronunciation accuracy, fluency, content completeness, etc.
4. **Generate Score**: Synthesize scores from each dimension to generate the final score (0-10 points, 0.5 point increments).

### 3.3 View Results

After scoring is complete, students can view:
- **Final Score** (0-10 points, 0.5 point increments)
- **Detailed Comments** (performance analysis for each dimension)
- **Reference Text** (for comparison and improvement)

## 4. Application Scenarios

### 4.1 Problem Practice

Directly answer speaking questions in the question bank for daily oral practice.

### 4.2 Competitions

Speaking questions can be added to competitions, and the leaderboard includes total speaking scores to reflect participants' oral proficiency.

### 4.3 Team Assignments

Team administrators can assign speaking questions in homework to uniformly train team members' oral abilities.

## 5. Scoring Criteria

AI scoring primarily considers the following dimensions:

### 5.1 Pronunciation Accuracy (40%)

Whether word pronunciation is accurate, and stress and intonation are natural.

### 5.2 Fluency (30%)

Whether the reading is fluent, without obvious pauses or repetitions.

### 5.3 Content Completeness (30%)

Whether the reference text content is completely read without omissions or additions.

## 6. Notes

- **Recording Environment**: It is recommended to record in a quiet environment to avoid background noise affecting scoring.
- **Microphone Quality**: Use a good quality microphone to ensure clear recording.
- **Reference Text**: Carefully read the reference text and ensure understanding before recording.
- **Multiple Attempts**: If not satisfied with the recording, you can re-record (specific number of attempts set by the question author).
