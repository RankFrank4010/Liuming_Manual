# 比赛规范

比赛是流明的在线竞赛功能：创建者组织一场竞赛，参赛者在线作答，按排行榜检验实力。比赛的意义在于**公平竞技**，一份真实的排名才值得被认可。本页规定创建者与参赛者双方应当遵守的规范。

## 一、创建者责任

比赛由创建者发起，创建者对整场比赛的质量与公平负责。

### 命题原创

- **命题原创**：比赛题目应与[题目与题单规范](/academic/problem)一致，满足原创性要求，不得抄袭、不得上传未经授权的资料。
- **题面与答案完整**：每道题应有完整、正确的题干、答案与题解。客观题需保证系统能自动判题；主观题需让批改人（或自批的参赛者）能依据答案准确判分。
- **数据自洽**：数据必须经过验证，避免因题目错误导致整场比赛作废。
- **AI 命题边界**：使用 AI 辅助命题时，题目必须经人工严格验证（见[生成式 AI 使用规范](/academic/ai)）。
- **命题协作**：创建者可邀请**命题人**共同维护题目，命题人对题目质量承担同等责任，应核实被邀请者的出题能力与诚信记录。

### 批改方式

创建比赛时需选择**批改方式**，三种方式各有责任约定：

- **仅创建者批改**：所有主观题只由创建者判分。创建者应保证在比赛结束后的合理时间内完成全部批改，及时更新排行榜。
- **指定批改人**：创建者指定多名批改人共同判分。批改人应按照标准答案公正判分，**不得对自己或熟人偏袒**；创建者负责协调与复核。
- **参赛者自批**：参赛者自己批改自己的主观题。创建者应在题目配置中提供清晰的标准答案，并在比赛说明中强调自批的诚信要求。

::: danger 批改不公是严重违规
批改人故意给特定参赛者错误判分（偏袒或打压），属于破坏比赛公平，将受到**警告、禁言**甚至**封禁**处罚。参赛者若发现判分明显不公，可通过举报与申诉渠道反映。
:::

### 公开比赛审核

- **公开比赛需审核**：公开（或团队公有等需要审核的）比赛在发布前需管理员审核，内容包括题目质量、描述与规则说明。
- **内容合规**：比赛标题、描述、题目不得包含违法、敏感、歧视、广告等内容，否则将被拒绝发布。
- **说明规则**：创建者应在描述中写明比赛的时间、作答方式、判分规则与注意事项，避免参赛者因信息不明而产生争议。

### 比赛管理

- 创建者可邀请**命题人**共同维护题目，命题人同样对题目质量负责。
- 比赛结束后，创建者应完成收尾：全部主观题批改完毕、导出试卷（如需）等。
- 比赛题目可被继承用于组卷或团队作业，因此题目质量不仅影响本场比赛，也影响后续的复用。

## 二、参赛者守则

参赛者应当遵守以下守则，维护比赛的真实与公平：

### 一人一账号

- **一人一账号**：每名参赛者只允许使用自己的账号参赛，一名参赛者只能有一个身份。
- **禁止代打**：不得让他人代替自己作答，也不得代替他人作答。代打双方都将被处理。
- **禁止共享账号**：不得共享账号、借用他人账号参赛。在私有比赛中借号混入指定参赛者名单同样违规。

### 独立思考

- **禁止抄袭**：不得复制他人作答，不得与他人共用答案。
- **禁止使用 AI 代答**：比赛作答应当反映你自己的能力。当比赛题目涉及计算、证明、写作或代码类作答时，不得直接使用 AI 生成答案提交。客观题由系统判题、主观题由批改人判分，AI 生成的作答会因缺乏个人思考痕迹而失真，一经查实按作弊处理。

::: warning 说明
流明平台自身提供 AI 批改与 AI 题解等辅助功能，但**比赛的作答环节**要求参赛者独立完成。赛前预习、赛后复盘使用学习资料没有问题，但赛中提交的答案必须是你的真实作答。
:::

### 赛中行为

- **禁止交流答案**：比赛进行中，不得在讨论区、团队、私聊等任何渠道交流或询问答案。泄题、对答案均属违规，发起者与传播者都会被处理。
- **遵守时间**：按比赛设定的开始 / 结束时间作答，逾期提交或赛后篡改作答不予认可。
- **禁止攻击系统**：不得攻击、逆向、爬取比赛数据，不得尝试获取题目答案、批改结果或他人作答，不得以任何方式干扰比赛系统运行。此类行为按「故意浪费本站资源」处理，后果见下文。

## 三、作弊后果

作弊行为一经查实，将按[社区规则及处罚](/policies/rule)处理：

| 情形 | 处理 |
| --- | --- |
| 抄袭 / 与他人共用答案 | 相关成绩作废，警告 → 禁言 |
| 代打、共享账号、冒名参赛 | 成绩作废，禁言 → 封禁账户 |
| 赛中交流 / 传播答案 | 涉事成绩作废，警告 → 禁言（发起者加重） |
| 使用 AI 代答 | 成绩作废，警告 → 禁言 |
| 攻击系统、爬取数据、逆向 | **永久封禁**，必要时连坐关联账户 |
| 屡次作弊、惯犯 | 依[违规周期](/policies/rule)加重处罚 |

::: danger 连坐制
若使用多个账号作弊，或被罚后注册、使用其他账户规避处罚，所有关联账户将追加同等或更重处罚；同一来源内频繁违规的，平台也会施加访问限制。不要抱有侥幸心理。
:::

所有处罚都以**封禁工单**形式记录，可申诉。作弊举报若属实，被举报人的成绩作废；若经查为恶意诬告，举报人同样会被处理。

## 四、重现赛与系列赛

- **重现赛**：创建者可对已结束比赛开启重现赛，克隆原比赛的题目与配置，重新开赛（见[比赛详解](/basic/competition)）。重现赛的题目同样适用本规范；设为公开仍需管理员审核。
- **系列赛规范**：举办系列赛（如复赛、决赛）时，应明确各场之间的衔接关系。不同场次的题目应独立验证质量，不得因「上场的题沿用」而省略审核。
- **成绩独立性**：每场比赛的排名独立计算，重现赛不代表历史成绩的延续。不得利用重现赛机制伪造「历史战绩」。
- **时间设置**：重现赛应设置合理的开始 / 结束时间，避免与正式赛时间冲突或产生歧义。

## 五、举报与申诉

- **举报作弊**：发现有人代打、抄袭、交流答案或攻击系统，可通过举报功能（或工单系统）提交，附上证据，管理员复核后处理。
- **举报题目问题**：发现比赛题目有错误、抄袭或内容违规，同样可举报。
- **申诉**：对判分结果有异议，或认为自己被误判 / 误罚，可通过工单系统申诉。被封禁用户通过封禁工单提交申诉并补充材料（见[账户与安全详解](/basic/account-safety)）。

::: tip 参赛体验建议
报名公开比赛前先阅读比赛描述中的规则与时间安排；比赛结束后及时查看批改结果，若有异议尽早申诉。尊重每一场比赛，也尊重每一个对手。
:::

## 六、组织一场比赛的检查清单

创建者赛前可以按下面的清单自查，避免常见的坑：

- [ ] 题目是否全部验证过：数据自洽、答案正确、无歧义、无抄袭？
- [ ] 主观题的批改人是否确认，是否已约定批改完成时间？
- [ ] 公开比赛是否已提交审核，并预留足够的审核时间？
- [ ] 比赛描述是否写清了时间、规则、判分方式与注意事项？
- [ ] 比赛结束后是否安排了批改收尾与成绩确认？

## 七、奖励与积分

流明比赛本身没有内置的排名奖励机制，但比赛作为社区活动同样受益于社区贡献规则：

- 比赛中的题目若同时贡献到题库并通过审核，会按题库贡献发放积分（见[积分与权益详解](/basic/rewards)）。
- 高质量的公开比赛是社区口碑的来源。主办比赛没有积分奖励，因此更应当出于「为社区服务」的初心来组织，而非追逐名次或虚荣。
- 不得以比赛名义进行任何形式的交易、收费或变相营利；不得以比赛为借口开展与学习无关的活动。

::: tip 办比赛的初心
一场好比赛的价值，是让参与者通过公平竞争检验自己的学习成果。把题目出好、把规则讲清、把批改做公，就是对社区最好的贡献。
:::

## 常见问题

**问：我是创建者，比赛题目能直接从题库选吗？**
答：可以。比赛题目可从题库选择，也可现场自定义。从题库选题可复用审核过的题目，质量更有保障；自定义题目则需自行把关质量。

**问：比赛中途退出会影响成绩吗？**
答：可随时退出比赛。退出的参赛者不再计入排名，已提交的作答如何处理以比赛描述为准。

**问：朋友之间互相批改主观题，会被认定为作弊吗？**
答：选择「参赛者自批」或「指定批改人」时，批改本身是正常机制；但如果批改人故意给关系密切者打高分、给他人打低分，则属于偏袒，会被处理。

**问：我怀疑某人作弊，怎么举报最有效？**
答：尽量提供具体证据（作答时间异常、作答风格与本人不符、交流答案的截图等），通过举报功能提交。附证据的举报更容易被核实。

**问：比赛时不小心看到了讨论区有人发答案，我有责任吗？**
答：如果你只是看到而没有传播，通常不会被罚；但若你使用了这些答案，成绩会被作废。正确的做法是忽略并举报泄题者。

**问：团队比赛和公开比赛规范一样吗？**
答：核心规范一致（命题、作答、作弊处理），团队比赛多了团队内的管理约定：团队管理员应负责成员管理、私题审核与比赛秩序，团队发生严重违规时团队本身也会被封禁（见[社区规则及处罚](/policies/rule)的连坐条款）。
