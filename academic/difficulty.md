# 难度星级判定标准

难度星级是题目最重要的元数据之一：它决定了题目在检索、组卷与学习推荐中的定位，也直接影响同学们对题目难度的预期。星级标得不准确，全站的难度体系都会失真。

本页把「这道题该标几颗星」说清楚。判定标准以数学学科为范例展开（锚定新高考 I 卷与数学竞赛），并按相同原则推广到所有学科；一切以平台实际运行的难度体系为准。

## 一、平台难度体系

平台的难度体系由**两套星级**与一套**动态数值评分**组成：

| 体系 | 档位 | 适用学科 |
| --- | --- | --- |
| 基础星级 | 送分 / 简单 / 中档 / 难 / 极难 | 全部学科 |
| 竞赛星级 | 竞- / 竞 / 竞+（各科共用入门档）；理科按本学科奥赛命名：数学 CMO/IMO、物理 CPhO/IPhO、化学 CChO/IChO、生物 CBO/IBO；非理科为 国- / 国 / 国家队 | 全部学科 |
| 动态难度评分（Rating） | 数值 100–3500 | 全部学科（系统按真实答题数据自动校准） |

- **基础星级**描述题目在常规学段考试（高考、中考、期末等）中的难度，所有学科通用。
- **竞赛星级**描述题目在学科竞赛中的难度层级，全部学科开放。理科按本学科奥赛体系命名（数学 CMO/IMO、物理 CPhO/IPhO、化学 CChO/IChO、生物 CBO/IBO）；非理科（语文、英语、地理、历史、政治）以通用竞赛星级（国- / 国 / 国家队）表述。
- **动态评分**由系统根据全站真实答题数据自动校准，是对星级的连续化补充（见[题库详解 · 动态难度评分](/basic/bank)）。

::: tip 关于档位数量
竞赛难度从入门到国际奥赛跨度极大，五档远不足以区分，因此竞赛星级在共用「竞- / 竞 / 竞+」入门档之上按学科细分：理科再分五档奥赛档位，非理科再分三档国家队档位。再辅以连续的动态评分，难题段也能被精确区分与排序。基础星级五档对应常规考试的结构，与动态评分共同覆盖从「送分」到「IMO+」的完整谱系。
:::

## 二、基础星级判定标准

基础星级回答的问题是：**在常规考试里，这道题处于什么位置？**

判定以本学科**标志性考试的题位结构**为锚——数学锚定新高考 I 卷。站到目标学段中等偏上学生的视角：能一眼看破的就是送分，要思考一会儿才动笔的就是中档，多数人做不出的就是难题。

### 数学：新高考 I 卷锚点

| 星级 | 判定要点 | 新高考 I 卷题位 |
| --- | --- | --- |
| 送分 | 直接套用单一公式 / 概念即得答案，几乎无思维量，读题即会做 | 第 1–4 题（单选前段） |
| 简单 | 单一知识点，一步常规转化或少量计算 | 第 5–6、9、12、15 题 |
| 中档 | 两到三个知识点综合，需中等量的转化与计算，思路常规但要多想一步 | 第 7、10、13、16、17 题 |
| 难 | 多知识点深度综合，需构造、分类讨论或较大的计算量，易错 | 第 8、11、14、18、19 题 |
| 极难 | 「难」中尤其困难者：压轴题的最后一问，需要非常规思路或长时间推演 | 第 18 / 19 题末问级别 |

### 推广到其他学科

判定原则相同：**锚定本学科标志性考试的题位结构**，而不是凭个人感觉。

- **送分**：卷面前段的默写、直接套用题（语文默写、英语单词 / 语法基础题、物理概念单选、化学方程式书写等）。
- **简单**：单一知识点的常规题（阅读题的前两问、实验题的直接填空等）。
- **中档**：两到三个知识点结合、需要规范步骤的题（语文现代文阅读主干题、英语长难篇阅读、物理多过程小题、化学推断题主干）。
- **难**：压轴综合题（语文作文升格、英语完形 / 阅读压轴、物理压轴计算、化学工业流程 / 实验设计）。
- **极难**：压轴题中最难的一问或最高区分度的一题。

## 三、竞赛星级判定标准

竞赛星级回答的问题是：**在学科竞赛里，这道题处于什么层级？**

以数学竞赛为锚：全国高中数学联赛分**一试**（高考题型）与**二试**（加试，四道题，通常分别对应平面几何、代数、数论、组合），其上为 **CMO**（六道题）与 **IMO**（六道题）。难度大致按「一试 → 二试第一题 → 二试第二题 → 二试第三题 → 二试第四题 ≈ CMO 第一 / 四题 → CMO 第二 / 五题 → CMO 第三 / 六题」逐级上升。

| 星级 | 判定要点 | 数学竞赛锚点 |
| --- | --- | --- |
| 竞- | 竞赛入门：一试中较难的题，或二试第一题的较易年份 | 一试压轴填空、二试一较易年份 |
| 竞 | 联赛二试第一题的标准难度 | 联赛二试第一题 |
| 竞+ | 二试第二题的较易者，或 CMO 第一、四题的较易者 | 联赛二试二较易年份、CMO 一 / 四较易 |
| CMO- | 二试第二题标准难度；CMO 第一、四题标准难度 | 联赛二试二、CMO 第一 / 四题 |
| CMO | 二试第三题较易者；CMO 第二、五题较易者 | 联赛二试三较易年份、CMO 二 / 五较易 |
| CMO+ | 二试第三题较难者；CMO 第二、五题较难者 | 联赛二试三较难年份、CMO 二 / 五较难 |
| IMO | 二试第四题；CMO 第三、六题较易者 | 联赛二试四、CMO 三 / 六较易年份 |
| IMO+ | CMO 第三、六题较难者，或达到 IMO 级别 | CMO 三 / 六较难年份、IMO 题 |

### 推广到其他理科

竞赛星级按本学科竞赛的晋级结构锚定（预赛 / 初赛 → 联赛 / 复赛 → 全国决赛 → 国际奥赛），档位命名沿用本学科奥赛缩写，「竞- / 竞 / 竞+」为各科共用的入门档：

- **物理**：入门档之上为 **CPhO- / CPhO / CPhO+**（全国决赛层级）与 **IPhO / IPhO+**（国际物理奥赛层级），对应「预赛 / 复赛 → 全国决赛（CPhO）→ 国际物理奥赛（IPhO）」。
- **化学**：入门档之上为 **CChO- / CChO / CChO+** 与 **IChO / IChO+**，对应「初赛 → 全国决赛（CChO）→ 国际化学奥赛（IChO）」。
- **生物**：入门档之上为 **CBO- / CBO / CBO+** 与 **IBO / IBO+**，对应「初赛 → 联赛 → 全国决赛（CBO）→ 国际生物奥赛（IBO）」。

### 通用竞赛星级（非理科）

语文、英语、地理、历史、政治等非理科科目同样开放竞赛星级，以**通用竞赛星级**表述（入门档同为「竞- / 竞 / 竞+」）：

- **国-**：准省级水平（省级竞赛中排名靠前的水平）。
- **国**：国家级水平（国家级 / 全国性赛事的获奖层级）。
- **国家队**：国家集训队水平（代表国家出战国际赛事）。

具体年份题目难度有波动，锚点取「典型难度」，判定时结合该层级常规难度把握。

## 四、判定总原则

无论哪个学科，星级判定遵循以下原则：

- **锚定参照系，不凭感觉**：基础星级锚定本学科高（中）考或学段考试的题位，竞赛星级锚定本学科竞赛的赛制层级。找不到参照物时，宁可先标保守，也不要随意标高。
- **站在目标学生视角**：难度是相对的——同一道题对初中生和高中生难度完全不同。始终以「该学段中等偏上学生」为参照。
- **星级是分类，动态评分是校准**：星级在提交时人工判定，决定检索、组卷与推荐的分组；动态评分由真实答题数据自动校准，弥补人工判定的偏差。两者相互配合，星级标错会污染动态评分的初始值（见[题库详解](/basic/bank)）。
- **如实判定**：刻意标高或标低难度，会干扰全站难度检索与学习推荐，属于不当行为（见[题目与题单规范](/academic/problem)）。

## 五、常见问题

**问：同一道题，有人觉得简单有人觉得难，以谁为准？**
答：以锚定参照系为准，不以个人水平为准。站到目标学段中等偏上学生的视角，对照本学科考试的题位结构判断。个别学生觉得难不影响星级，动态评分会持续反映真实答题数据。

**问：竞赛题能只标基础星级吗？**
答：可以。竞赛题同时满足两者时，建议两套都标：基础星级描述它放到常规考试里是什么难度（很多竞赛入门题其实只到「中档」），竞赛星级描述它在竞赛里的层级。改编过的竞赛题按改编后的实际难度判定。

**问：五档会不会不够分？**
答：基础星级对应常规考试结构，五档足够；竞赛段另有按学科细分的竞赛星级（理科奥赛档、非理科国家队档），加上连续动态评分，难题段也能精确区分。若仍嫌不足，可借助动态评分排序（见[题库详解](/basic/bank)）。

**问：AI 出的题，星级怎么定？**
答：AI 出题后必须人工按本页标准校验难度（见[生成式 AI 使用规范](/academic/ai)），不能直接采信 AI 自评的难度。

**问：发现别人标错星级怎么办？**
答：可举报该题，管理员复核后会按实际情况调整；刻意标高 / 标低多题的，按违规处理。
