# 题解与文章规范

流明的讨论区用于交流学习心得与题目解法；专栏则用于发布文章，分享经验与知识。无论是讨论区的一个帖子，还是专栏的一篇长文，本质上都是在向他人传递知识。

知识传递的前提是**正确**。一篇错误的题解会让读它的人学到错误的东西，一次敷衍的分享会浪费读者的时间。本页规定在讨论区与专栏发布内容时应当遵守的规范。

## 一、内容质量

### 正确性优先

- **解法必须正确**：发布题解前，请确认解法本身正确、过程无跳步、结论与题目的标准答案一致。若不确认，请说明「仅供参考，欢迎指正」。
- **诚实标注不确定性**：对存在争议或多种解法的题目，可以介绍不同思路，但应如实说明各自的前提与局限，不把猜测写成定论。
- **勘误义务**：发现自己的题解有误时，应尽快更正或删除，避免错误继续传播。更正时可在正文中说明「已修正」，让后来者知道版本变化。

::: danger 发布错误题解不是「言论自由」
故意发布错误题解、用错误内容误导他人，属于扰乱学术秩序，视情节会被**警告、禁言**。无意写错但拒不更正、持续误导的，同样会被处理。
:::

### 讲清楚思路

一篇合格的题解至少应包含：

- **思路说明**：为什么想到这个方法，第一步从哪里切入，而非只丢一堆公式。读者需要的不是「答案是什么」，而是「怎么想到这个答案」。
- **必要证明**：证明题给出完整的推理链；应用题说明每个条件如何使用；结论给出必要的论证，不跳关键步骤。
- **答案与验证**：给出最终答案，并在可能时说明验证方式（如代入检查、特殊值检验），帮助读者确认结果。
- **常见错误提醒（加分项）**：指出容易踩的坑、常见的错误解法和误解，这类内容对读者的帮助往往最大。

### 避免无意义内容

- 不发布「求答案」「答案是什么」这类不构成内容的求助灌水帖（求助请说明自己的思路与卡点）。
- 不发布表情包刷屏、纯「顶」「路过」等无信息量回复。
- 不发布广告、推广链接或与学科学习无关的内容。
- 不在讨论区反复发布内容完全相同或高度雷同的帖子。

## 二、格式规范

讨论区与专栏都支持 Markdown 与 LaTeX 公式排版，格式得当的内容更易读、更受欢迎：

- **结构清晰**：长文使用标题分节（## 三级标题），正文用小节。一篇文章的结构应与题目步骤对应，方便读者按序阅读。
- **公式用 LaTeX**：理科内容中的公式应使用公式排版（`$...$` 行内公式、`$$...$$` 独立公式），不要把公式写成纯文本或贴图。
- **代码可读**：若涉及代码或伪代码（如算法讲解、编程思路），使用**代码块**（``` 围栏）并标注语言，保持缩进与命名规范。
- **长代码折叠**：篇幅较长的代码应使用**折叠块**（details）收纳，避免一屏贴满代码淹没正文。正文应解释关键逻辑，而不是让读者自己读完整段代码。
- **图片合理**：配图应清晰且与内容相关，手写解题过程等图片建议先处理方向与亮度再上传。
- **标题精准**：帖子或文章标题应概括内容（如「M0001 的另类解法」），避免「帮我看看」「求助」这类无信息量的标题。

::: tip 好排版的标准
好的排版让读者**只看小标题与公式就能抓住全文脉络**。写完先自己通读一遍：有没有一眼看不到重点的段落？有没有该用公式却写成文字的式子？
:::

## 三、原创与引用

- **不抄袭**：不得把他人（其他用户、网站、出版物）的题解或文章整体搬运、洗稿后以自己的名义发布。
- **引用需标注**：引用他人的方法、结论、证明或文字时，应**明确标注来源**（原作者、链接、书名、网页等）。引用他人解法时附上原文链接是最基本的尊重。
- **不侵犯版权**：不得上传受版权保护的整篇教材内容、收费资料原文等。分享知识点可以，整段搬运不行。
- **借鉴理念可以，照搬文本不行**：学习他人思路后用自己的话重写，并注明参考来源，这是健康的交流；一字不改地复制粘贴，则不是。

::: warning 讨论区与专栏的差异
讨论区的帖子用于交流讨论，语气可以轻松；专栏文章是「出版物」，应当更完整、更规范。将低质量的帖子原样搬进专栏并不合适，专栏文章应达到本篇所列的内容与格式标准。
:::

## 四、AI 辅助披露

使用生成式 AI 辅助写作（润色、排版、生成草稿、检查错漏）是被允许的，但必须遵守披露义务：

- **必须披露**：文章或题解若使用了 AI 辅助，应在文末**如实说明 AI 的具体贡献**（如「本文使用 AI 润色文字」「解题思路由本人完成，AI 辅助检查计算」）。
- **关键内容不得照搬**：核心思路、论证、证明与代码，应来自你自己的思考与验证，不得直接照搬 AI 的输出（详见[生成式 AI 使用规范](/academic/ai)）。
- **作者负责**：无论是否使用 AI，你都对发布内容的正确性与原创性负全部责任，AI 不能成为错误或抄袭的挡箭牌。

## 五、专栏分类建议

发布专栏文章时，为方便读者检索，建议按以下方向分类：

- **题目详解**：某道题（尤其是难题、经典题）的详细分析与多种解法，可附上题号（如 `M0001`）便于对照。
- **专题归纳**：某知识点的系统整理，如「初中几何辅助线归纳」「英语从句一图流」，适合配合题单学习。
- **方法总结**：解题方法、学习方法的经验分享，如「如何检查计算错误」「证明题从哪下手」。
- **学习记录**：个人学习经历、备考记录，注意保护个人隐私，不泄露他人信息。

## 六、违规处理

讨论区与专栏的违规行为按[社区规则及处罚](/policies/rule)处理：

| 情形 | 处理 |
| --- | --- |
| 低质量灌水、无意义回复 | 警告、删帖 |
| 辱骂、人身攻击、歧视性言论 | 警告 → 禁言（依情节与再犯情况加重） |
| 抄袭 / 洗稿、未标注引用 | 删帖、警告 → 禁言 |
| 侵权内容（整篇转载受版权保护内容） | 删帖、封禁论坛 → 封禁账户 |
| 多次违规、惯犯 | 依[违规周期](/policies/rule)加重处罚 |

**举报通道**：发现违规帖子或文章，可通过举报功能（或工单系统）提交，管理员复核后处理。处理与申诉流程见[账户与安全详解](/basic/account-safety)。

::: tip 良性循环
讨论区与专栏的价值来自每一位认真分享的用户。你的一次认真回答，可能正是另一位同学卡了三天的那道题的答案。请认真对待你发布到社区的每一个字。
:::

## 七、如何写好一篇题解（示例结构）

以一道理科证明题为例，一篇结构完整的题解可以这样组织：

1. **题干回顾**：用一两句话复述题目，标注题号（如 `M0001`），方便读者定位。
2. **思路分析**：说明考点是什么、为什么从这个角度切入，列出可能的思考路径与排除的理由。
3. **分步解答**：按步骤展开，每一步对应一个公式或一段论证，关键步骤单独成段，不跳步。
4. **结论与验证**：给出最终答案，并说明如何检验（代入、特殊值、反证等）。
5. **拓展思考**（可选）：变式、推广、常见误区。

这样写的好处是读者可以按图索骥：先看思路建立直觉，再按步骤核对过程，最后用验证方法确认结果。无论篇幅长短，保持这个骨架，你的题解就不会是「一堆公式的堆砌」。

## 八、讨论区交流礼仪

流明讨论区的交流氛围由每一位参与者共同维护。除了内容规范，还请注意：

- **友善**：就题论题，对事不对人。指出他人解法有误时说明理由，不要冷嘲热讽。
- **耐心**：对初学者的问题耐心解答，好为人师也要授人以渔，讲清思路而非只丢答案。
- **克制**：不刷屏、不连发、不顶旧帖。回复前先看是否已有相同回答。
- **尊重**：不同解法之间没有高下，只要正确都值得被认真对待。批评解法，不攻击人。

好的讨论区氛围会让更多人愿意分享，而更多人的分享反过来又让每个提问者更快得到答案。

## 常见问题

**问：在讨论区问作业题答案算违规吗？**
答：提问本身不违规，但应说明自己的思路与卡点，而不是只求答案。长期只求答案、从不思考的帖子会被视为低质量内容。

**问：搬运知乎 / 博客上的解题方法可以吗？**
答：可以分享，但必须**标注来源并附链接**，最好用自己的话重述。直接整段复制属于侵权式搬运。

**问：我的文章被举报了，怎么办？**
答：管理员会复核举报。若内容确实违规会被处理（可申诉）；若举报不实，文章不受影响。

**问：专栏文章可以被转载到别处吗？**
答：由原作者决定。转发他人专栏文章请先征得同意并标注出处。

**问：题解用可视化模式还是代码模式写更好？**
答：都可以。可视化模式所见即所得，适合不熟悉 Markdown 的用户；代码模式适合需要精确控制格式的场景。两种模式保存的都是 Markdown，可随时切换。
