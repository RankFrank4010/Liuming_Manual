# 学术规范总览

流明是一个面向小学至高中全学段、覆盖九大学科（数学、语文、物理、化学、生物、英语、地理、历史、政治）的刷题与学习社区。这里既有题库、题单、整卷库等由社区共同积累的学习资源，也有比赛、团队、专栏、讨论区等协作空间。

资源与活动越丰富，就越需要一套共同的准则来保证它们的质量与可信度。**学术规范**正是为此而设立：它明确了题目、题解、文章、AI 辅助与比赛等各类学术活动的行为边界，保护每一位认真出题、认真答题、认真写文章的用户，也让流明的每一份学习资料经得起推敲。

## 为什么需要学术规范

学术规范的存在，首先是为了**保障学术诚信**。一道题如果被照搬抄袭、一道题解如果只是拼凑的错误内容，都会直接误导后来练习的同学，污染整个题库。一份比赛的排名如果被代打或作弊污染，对所有认真参赛的同学都不公平。

其次是为了**保障公平**。比赛有统一的规则，批改有统一的流程，举报与申诉有统一的通道。规范让每一个环节都可预期、可追溯、可申诉，而不是凭个人喜好随意处置。

最后是为了**保障质量**。规范不是束缚，而是底线之上的方向指引。它告诉贡献者怎样把一道题出好、把一篇题解写好、把一场比赛组织好，让整个社区的知识积累越来越扎实。

::: tip 规范与社区规则的关系
学术规范是[社区规则及处罚](/policies/rule)在学术活动领域的具体化。处罚类型与流程（警告、禁言、封禁论坛、封禁账户、违规周期、连坐等）以社区规则为准，本板块说明这些规则如何应用于学术场景。
:::

## 核心理念

流明的学术规范围绕四个理念展开，本板块所有条款都是它们的体现。

### 规范化

规范让内容可被检索、可被审核、可被复用。题目有学科、学段、题型、难度的固定体系，题单有主题与标签，文章有结构与排版的约定。没有这些约定，海量的内容只会变成一团乱麻。对贡献者而言，规范化意味着「有章可循」，照着标准写，被采纳的概率更高；对学习者而言，规范化意味着「可预期」，任何一份资料拿起来都知道该怎么用。

### 原创性

社区积累的资料应当来自真实的思考与创作。原创不要求每句话都前无古人，它要求的是：引用要标注、借鉴要说清楚、抄袭要禁止。一套题库的价值恰恰建立在「每一题都是可以追到来源、可以信任的」这一前提之上。一旦失去原创性，题库就退化成了一堆搬运来的、无人负责的文本。

### 可追溯

流明的每一项治理操作都可追溯：题目的审核日志记录审核人与原因，工单系统为每次举报、申诉、封禁生成事件时间线，违规周期集中记录每一段违规。可追溯既约束被处置者（无法抵赖），也约束处置者（无法暗箱操作）。出了问题，翻记录就能还原事实。

### 公平竞争

比赛的结果必须真实反映能力。一人一账号、禁止代打、禁止交流答案，规则面前人人平等。比赛的含金量来自公平：只有当每位参赛者的排名都只取决于自己的实力时，站上排行榜前列才值得骄傲，观赛者也才会相信这份排名的意义。

## 适用范围

本板块规范适用于流明上所有与学术内容相关的行为，包括但不限于：

- 向题库贡献题目、提交修改意见（新版本）。
- 创建与公开题单。
- 在讨论区发帖、在专栏发布文章与题解。
- 使用生成式 AI 辅助学习、写作或批改。
- 创建比赛、报名参赛、担任批改人或命题人。
- 上传整卷到整卷库。

即使没有明确列出的行为，只要损害了学术诚信、内容质量或社区公平，管理员都可以依据[社区规则及处罚](/policies/rule)中的原则进行处理。

::: danger 违规周期与再犯
处罚不是一次性的。依据[社区规则及处罚](/policies/rule)，自第一次犯规起 365 天内构成一个违规周期，周期内再次违规会延长周期并加重处罚。反复违反相同规则会被认定为**再犯（惯犯）**，处罚逐次加重。不要抱着「偶尔违规无所谓」的心态，你的每一次违规都会被记录。
:::

## 违规与处罚概览

依据违规的严重程度，学术活动中的违规行为可能受到以下处罚（详见[社区规则及处罚](/policies/rule)）：

| 违规类型 | 常见情形 | 可能的处罚 |
| --- | --- | --- |
| 轻度违规 | 题面不清晰、格式混乱、标签错误 | 拒绝审核并附原因，退回修改 |
| 一般违规 | 搬运他人题解未标注、低质量灌水内容 | 警告、禁言 |
| 严重违规 | 抄袭题目或题单、恶意提交、作弊、攻击系统 | 封禁论坛、封禁账户 |
| 特别严重 | 侵权、破坏平台运行、屡教不改 | 永久封禁，必要时连坐关联账户 |

处罚并非目的，纠偏才是。绝大多数轻度违规在审核阶段就被拦截：题目被拒附有原因，改好重提即可。真正会升级为封禁的，通常是反复、故意、恶意的行为。平台为每一位用户保留了申诉通道：被拒的贡献可以申诉，被封禁的账号可以申诉，处理不公可以申诉。

::: tip 被拒或被处罚后怎么办
被拒绝的题目或题单贡献可以发起**申诉**请求复核；被封禁的用户可以通过**封禁工单**提交申诉并补充材料。申诉的具体流程见[账户与安全详解](/basic/account-safety)。
:::

## 常见问题

**问：不小心违规了，会不会直接封号？**
答：不会。处罚按情节分级，首次轻度违规通常以警告或拒绝审核为主。只有严重违规、反复违规（惯犯）或故意破坏行为才会升级到封禁。并且所有处罚都可申诉。

**问：借鉴别人的题解算不算抄袭？**
答：学习他人思路后用自己的话重写并**标注来源**，属于正常交流；整段照搬不标注，则属抄袭。区别在于是否诚实交代了来源。

**问：用 AI 帮我润色文章，需要告诉别人吗？**
答：需要。只要在创作中使用了 AI 辅助，就应在文末披露其具体贡献。这不丢人，反而是负责任的表现。详见[生成式 AI 使用规范](/academic/ai)。

**问：被拒绝的题目还有机会通过吗？**
答：有。按拒绝原因修改后重新提交即可；若认为审核有误，可发起申诉。审核全程可追溯，每一轮都有明确原因。

**问：规范会变化吗？**
答：会。与[社区规则及处罚](/policies/rule)一样，本板块也会根据实际情况更新。涉及学术活动的重要调整会同步到对应页面，参与社区贡献前建议留意。

## 贡献者须知

参与学术贡献（出题、建题单、写文章、办比赛）之前，请先确认以下几点：

- **你已读过对应规范**：出题前读[题目与题单规范](/academic/problem)，发文章前读[题解与文章规范](/academic/article)。规范不长，但能帮你少走弯路。
- **你了解审核流程**：题目、公开题单、公开比赛都需要管理员审核，审核需要时间，请耐心等待；被拒不意味着针对你，按原因修改即可。
- **你清楚积分规则**：题目与题单贡献**审核通过**时才会发放积分，积分可兑换额度等权益（见[积分与权益详解](/basic/rewards)）。质量是获得积分的前提，不是数量。
- **你愿意为内容负责**：发布到社区的内容会长期存在，被许多后来者阅读。写下的每一行都要对得起读者。

## 遇到问题怎么办

| 情况 | 做法 |
| --- | --- |
| 题目 / 题单被拒 | 查看拒绝原因，修改后重新提交，或发起申诉 |
| 发现违规内容 | 通过举报功能提交，附上理由，管理员复核 |
| 被封禁 / 被误判 | 通过封禁工单提交申诉，可补充材料 |
| 对判分有异议 | 通过工单系统申诉 |
| 规则看不懂 | 在讨论区提问，或联系管理员 |
