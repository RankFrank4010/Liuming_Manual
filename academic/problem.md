# 题目与题单规范

题库是流明的核心。题库中的所有题目都由社区用户贡献，经管理员审核后发布；题单按主题整理题目，公开题单同样需要管理员审核。题目的质量直接决定了全站同学练习与学习的效果，因此贡献题目与题单是一件需要认真对待的事。

本页规定贡献题目与题单时应当遵守的规范。违反规范的行为可能被拒绝、被举报，情节严重的将依据[社区规则及处罚](/policies/rule)受到警告、禁言、封禁等处罚。

## 一、原创性要求

**题目必须是原创的，或经过明确授权的改编。** 这是题库可信度的基础。

### 不得抄袭

- **不得复制**：不得复制其他平台、教辅资料、老师课件或其他来源的题目作为自己的贡献。复制既包括整体照搬，也包括「换几个数字」式的搬运。
- **改编需谨慎**：改编他人题目（修改数据、更换情境、变换设问）时，若核心结构与考点仍与原题实质相同，应视为引用而非原创，需要标注来源并取得授权（若涉及版权内容）。
- **翻译也属于改编**：把其他语言的题目翻译成中文提交，若未注明原出处，同样构成侵权式搬运。

### 引用需标注

若题目确实引用了他人的思想、数据、材料或题目框架，应在题解或题目描述中**注明出处**。出处应尽量具体：

- 教材与教辅：标注书名、版本、页码或单元。
- 真题与竞赛：标注年份、地区、赛事名称。
- 网络资源：标注来源链接与作者。

标注不是「露怯」，而是让题目可以追溯到出处，便于读者核对，也保护原创者的权益。

### 侵权红线

不得上传受版权保护且未获授权的教材原文、真题试卷、收费资料等。注意：

- 整卷库的上传同样适用此规则（见[整卷库详解](/basic/paper-uploads)）。
- 「网上都能找到」不等于「可以随便搬」。授权是搬运的前提，不是普遍默认。
- 拿不准时，宁可标注来源、说明改编，也不要装作原创。

::: danger 抄袭的后果
抄袭他人题目或上传侵权内容，属于严重违规。一经查实，轻则题目被拒并**警告**，重则**禁言、封禁账户**，并计入[违规周期](/policies/rule)。被抄袭的原创作者可以通过举报通道投诉。
:::

## 二、题面质量标准

一道合格的题，首先应当是一道**清晰、严谨、可独立完成**的题。管理员审核时会重点关注以下方面：

### 表述清晰

- **题意无歧义**：题干应完整交代条件、对象与所问，不依赖题面外的默认前提（除非是公认的教学约定，如「在小学范围内」）。
- **语言规范**：使用规范学科用语，避免口语化、不完整句式或自造符号。语文题注意标点与用字，英语题注意拼写与大小写。
- **条件自洽**：题目给出的条件应当相互不矛盾，且足以支撑唯一（或题目要求的）答案。涉及数据时，注意数值是否经过验证（如几何题的三边是否真的构成三角形、应用题的数字是否算得开）。

### 公式与排版

- **公式使用 LaTeX 排版**：数学、物理、化学、生物等理科题目中的公式、符号应当用公式输入，而不是把公式写成纯文本或图片。编辑器支持**可视化输入公式**，可图形化拼搭 LaTeX 并实时预览，无需记忆语法（见[输入与编辑器详解](/basic/editor)）。
- **排版整洁**：善用编辑器排版题干结构（编号、分行、列表），避免一大段文字挤在一起。公式前后注意间距，分数、根号、上下标应正确表达。

### 答案与题解

- **答案完整正确**：客观题（填空、选择、判断、等价表达式等）必须提供准确的答案，否则系统无法自动判题。
- **填空注意容差**：填空题要说明**容差要求**是否适用（如精确匹配、数值容差 ±0.01、百分比容差、常数求值），避免因精度问题误判。
- **多选明确模式**：选择题要明确是**单选、多选还是不定项**，并给出完整选项。多选或不定项需说明判分规则（如漏选、错选如何处理），避免争议。
- **题解可缺但不该空**：题解是可选字段，但一份好的题解能让题目更有价值。若确实无法提供题解或答案，应显式标记为「缺失」，交由审核判断。对证明题、应用题等主观题，建议附上**标准解答或参考答案**，方便批改。

### 多小题拆分

- **拆分合理**：一道大题拆分为多个小题时，小题之间应有清晰的递进或并列关系，各自可独立作答、独立判分。避免把互不相干的题目强行拼成一道多小题题。
- **分别给答案**：每个小题都应有对应的答案与判分依据，避免出现「部分小题无答案」的残缺大题。
- **标注分值（如适用）**：若题目用于比赛或组卷，注意在题目配置中合理设置小题分值与评分规则。

::: tip 一道好题的标准
好的题目不只是「能做出来」，而是**考点明确、数据可算、答案唯一、错了能讲清**。出题时站在做题人的角度读一遍题面，往往能发现很多问题。
:::

## 三、格式与提交规范

贡献题目时（路径：导航「贡献题目」），请按以下要求填写：

- **标题**：简洁、能反映题目内容。避免无意义标题（如「题目1」「随便出的」）或与学科无关的标题。
- **学科与子学科**：正确选择学科。数学、物理、化学、生物、地理、历史还细分了子学科，应选择最贴近的（如「几何」「力学」「中国古代史」）。
- **学段**：按题目实际适用学段选择（小学低年级 / 小学高年级 / 初中 / 高中）。注意物理、化学、地理、历史、政治不设小学学段，选择时以平台显示为准。
- **难度星级**：如实选择**基础星级**（送分 / 简单 / 中档 / 难 / 极难）；理科可额外选择**竞赛星级**（竞- ~ IMO+）。刻意标高或标低难度会干扰全站的难度检索与学习推荐，属于不当行为。
- **题型**：按题目真实作答方式选择（填空 / 选择 / 等价表达式 / 判断 / 证明 / 应用题 / 简答 / 作文 / 听力等）。不同学科支持的题型不同，以平台显示为准。
- **标签**：选择贴切的知识点标签；若无合适标签可提案新标签。标签是检索与学习推荐的重要依据，**不得使用与题目无关的标签**凑数。
- **编辑器模式**：可视化模式与代码模式均可，二者保存的都是 Markdown，可随时切换。理科公式建议使用**可视化输入公式**功能，从源头保证 LaTeX 正确。

::: warning 内容安全
题目内容不得包含任何违法、敏感、色情、暴力或歧视性内容，不得涉及政治敏感话题。此类内容一经发现将直接拒绝，并可能被严肃处罚（见[社区规则及处罚](/policies/rule)）。
:::

## 四、附件规范

题目支持上传图片与听力音频附件，附件应当服务于题目本身：

- **图片附件**：上传**题干配图 / 插图 / 题解图**时，注意图片清晰、方向正确、与题目内容对应。题解用途的图片会作为本题的题解展示。不得上传与题目无关的图片、表情包或广告图。
- **听力音频**（仅英语听力题）：上传**仅音频格式**的听力音频（最大 50MB），并填写**听力材料**（听力原文），两者应内容一致。听力音频应清晰、无杂音、无剧透（不要在读题前暴露答案）。
- **文件来源**：附件应当是自行制作或已获授权的材料。截图他人资料时应确认不涉及版权与隐私问题。
- **附件与题干一致**：插图应与题干描述吻合，听力音频应与听力材料一致。附件与题干矛盾会直接导致题目无法作答。

## 五、审核与修改流程

提交题目后，题目会经历以下流程，请知悉并配合：

1. **待审核（pending）**：提交后系统自动生成题号（如 `M0001`），题目进入审核队列。
2. **管理员审核**：管理员在审核台检查题干、答案、题解与附件，作出**通过（发布）**或**拒绝（附原因）**的决定。
3. **查看结果**：在「我的贡献」页面查看已通过 / 被拒状态及拒绝原因。
4. **修改重提**：被拒或需要修改时，更新题目内容后重新提交，题目会**重新回到待审核状态**，需再次审核。
5. **全程可追溯**：审核操作（审核人、时间、原因）全程记录。

### 修改意见（新版本）

对已发布的题目，除直接修改外，还可以提交**修改意见**（完整的新版本）：

- 修改意见同样走**审核流程**，审核通过后替换线上题目。
- 历史修改意见可查看与追溯，因此**修改不是「偷偷改掉」**，而是透明的版本更替。
- 当题目被举报或管理员发现内容问题时，优先通过提交修改意见来更正，这是比重新出一题更合理的做法。

### 申诉

对被拒绝的题目贡献，如果认为审核有误，可以发起**申诉**请求复核。申诉会进入工单系统，由管理员重新处理并给出最终结果。

::: tip 申诉流程
申诉与工单的具体操作见[账户与安全详解](/basic/account-safety)中的「内容申诉」与「举报与工单系统」章节。
:::

## 六、题单规范

题单是按主题整理的题目合集，适用于专题练习、备考分享、比赛与作业的题目来源。创建题单时应当注意：

- **主题明确**：标题与简介应清楚说明题单的主题与适用人群（如「初二数学 · 一次函数专题」）。避免标题与内容不符，或含义不明的标题。
- **内容相关**：题单中的题目应当与主题相关。把无关题目塞进题单（尤其为了凑数量）属于低质量贡献，公开题单可能因此被拒。
- **顺序合理**：善用拖拽排序，让题目循序渐进，形成学习路径；可为题目添加备注说明。
- **标签与学科**：正确填写学科与标签，便于检索。
- **不照搬他人题单**：整理他人已公开的题单内容需注明借鉴来源；不得整体复制他人题单后以自己的名义公开。
- **公开需审核**：公开题单提交后进入待审，管理员批准后对全站可见。若只想小范围分享，可设为私有并关联到指定团队。
- **及时维护**：题单引用的题目若已被修改或下架，注意检查题单是否仍可正常练习。
- **可复用性**：题单常作为比赛、团队作业、组卷的题目来源（可从题单一键继承题目），整理时请确保题目质量过关，因为你的题单会被别人用来组卷与布置作业。

::: warning 恶意行为
**恶意贡献**（如批量提交垃圾题目、故意提交重复或无意义内容、用题单塞无关题目、抄袭他人题单等）不仅浪费管理员审核资源，也属于「浪费本站行政资源」，会按[社区规则及处罚](/policies/rule)处理，可能被**禁止相关权限**甚至封禁。
:::

## 七、违规后果

涉及题目与题单的违规行为，按严重程度分级处理：

| 情形 | 处理 |
| --- | --- |
| 题面不清晰、格式错误、标签不当 | 审核拒绝并附原因，退回修改 |
| 多次提交低质量 / 无意义题目 | 警告；情节严重者禁止贡献权限 |
| 抄袭题目、上传侵权内容 | 警告 → 禁言 → 封禁（按情节与再犯情况） |
| 恶意灌水、批量垃圾贡献 | 禁言 → 封禁账户 |
| 屡次违规、惯犯 | 依[违规周期](/policies/rule)加重处罚 |

所有处罚都以**工单**形式记录，可申诉。贡献者获得积分的前提是内容真实有效：题目 / 题单贡献**审核通过**时才会发放积分（见[积分与权益详解](/basic/rewards)），抄袭或无效贡献不会获得积分，反而可能失去贡献资格。

::: danger 请勿心存侥幸
违规周期会记录每一次违规并自动计算再犯。不要试图用多个账号规避处罚，**连坐制**会追罚所有关联账户（见[社区规则及处罚](/policies/rule)）。
:::

## 常见问题

**问：我改编了一道教辅上的题，算原创吗？**
答：若核心结构、考点与数据实质相同，属于改编而非原创，应标注来源；若只是参考其考点后全新设计，属于原创。拿不准时建议标注来源。

**问：被拒的题目重复提交会通过吗？**
答：不会。不修改内容就重复提交同一题，会被视为浪费审核资源。请先按拒绝原因修改，再重新提交。

**问：听力音频可以不是自己录的吗？**
答：可以，但必须是已获授权使用、且内容与听力材料一致的音频。来自收费资料或他处录制的音频需确认授权。

**问：题单可以被别人改吗？**
答：题单默认由创建者维护。若希望多人协作，可关联到团队，在团队内共享管理。

**问：我的题被举报了怎么办？**
答：举报会生成工单，管理员复核后处理。若认为举报不实或处理不当，可通过工单申诉。
